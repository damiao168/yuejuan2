# S02 — 考试、试卷、题目与题库

## 结论

本轮静态检查的生产入口和 PostgreSQL 实现中，未确认租户越权或准备快照缺陷。发现的准备状态与评分运行路径差异列在 [S04.md](S04.md) 的 S04-F01：准备提示按“题型存在某种自动辅助能力”分类，但常规评分运行不会为主观题触发该辅助流程。该点的代码行为已确认，是否违反产品预期仍属疑似。

## 覆盖与证据

- 考试候选人快照：`services/api-gateway/internal/exam/candidate_snapshot_postgres.go:20-48` 在事务中按 tenant/exam 重建快照；相关查询继续限定 exam class、学生状态和租户。`paper` readiness 在 `services/api-gateway/internal/paper/store_postgres_configuration.go:338-437` 锁 exam 并重算配置，确认前后候选人集合未变化后，在同一事务保存 readiness 与快照；`StartCollection` 在 `:440-494` 再核对配置哈希和已通过的 readiness 快照。
- 试卷准备检查：`services/api-gateway/internal/paper/template_validation.go:175-208` 检查答案、rubric、已锁定模板及全部题目区域覆盖，`Ready` 由阻塞检查决定；人工题型 advisory 不改变 `Ready`。完整题型枚举和覆盖 mirror 在 `paper/scoring_coverage.go:12-57`。
- 题目及题库：检查了 `paper/question_postgres.go`、题库发布／导入／物化 Postgres store 与相关 migration。读取和写入路径以 tenant ID 过滤，题库发布的 exam materialization 在调用方事务内并要求试卷仍可修改；未找到用户提供的 tenant ID 可切换租户查询的入口。
- 生产路由／装配：已对照 exam、paper、assessment、questionbank 路由与 Postgres stores，未以 Memory store 的测试语义代替生产结论。
