## 必要复杂度与适用限制

- TLS 信任链、证书主机名、私钥配对与有效期检查，迁移顺序、低权限账号、租户隔离、原评教师回避、生产镜像锁定与备份恢复有实际边界。精简对象是安装者搬运配置与判断依赖的工作，不是这些检查本身。
- 当前证书生成器拒绝覆盖已有目录；已有短期测试目录出错后，自动删除并重建会破坏失败恢复依据，因此不推荐“删掉 certs 后重试”。
- 本地模型已实现断点续传、重试、大小与 SHA256 校验；日常已有文件也可复用。不能误报为每次启动都会重新下载。首次是否需要下载和运行，仍应取决于实际使用模式。
- 安装标记在首次管理员创建之后、登录 smoke 之前落盘，代码明确为防止短暂 HTTP 故障导致重复创建管理员；这是合理边界。进一步优化可分别记录“账号已创建”和“验收已完成”，提供重试验收入口，但本次未完整阅读 smoke-test 实现，不将其判定为已证实缺陷。
- README 和 Compose README 只审读相关段落；Compose、示例配置和 preflight 仅核实相关行或盘点，清单保持 `pending`。没有验证当前机器实际部署是否采用上述默认值，也未执行升级或异常恢复演练。
