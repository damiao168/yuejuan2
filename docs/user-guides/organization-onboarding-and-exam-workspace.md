# 机构启用与考试工作区操作说明

## 适用人员

本说明用于首次部署后的学校管理员。管理员只需使用 Web 页面即可完成基础机构启用，不需要数据库、Swagger 或命令行操作。

## 首次启用

1. 使用部署负责人提供的机构代码、管理员用户名和首次密码登录。
2. 打开“组织与用户”。系统会根据已存在的真实数据显示当前进度。
3. 填写机构名称和机构代码。机构代码建议使用稳定的英文或数字简称，创建后不要随意变更。
4. 创建当前学年和年级，再创建班级。班级代码在同一学校内应保持唯一。
5. 下载学生导入模板，选择 Excel（.xlsx）或 CSV 后确认字段映射。整批校验通过后才新增名册；有错误时修正整份名单后重试。导入完成后，在学生列表中为需要登录的学生开通账号并设置初始密码。
6. 在“人员与权限”新增教师，填写姓名、登录用户名、所属学校和任教学科，并填写至少8个字符的初始密码及相同确认。创建回执提供账号和学校代码；请通过可信渠道将初始密码交给本人。教师首次登录必须先改密，再重新登录；阅卷与复核任务另行分派，不绑定教学班级。学校管理员通过独立管理员入口邀请，不在教师表单中选择管理职责。
7. 创建第一场考试，选择学校、班级、科目、总分和阅卷方式。
8. 页面显示全部步骤完成后，进入考试工作区继续配置试卷。

退出页面或重新登录不会丢失已创建的数据。向导进度来自学校、年级、班级、学生、用户和考试记录，不依赖当前浏览器。

## 学生名册与登录账号

- 点击“新增学生”时，必须填写班级、学号、姓名、初始密码和确认密码。学生与账号一并保存，任一步失败都不会留下半份记录。性别可选。
- 学号同时作为学生登录账号，同一学校内不能重复。学生使用列表显示的学校代码、学号和密码登录；初始密码至少 8 个字符，首次登录必须修改。密码不会显示在列表中，也没有系统默认密码。
- 批量导入只新增名册，账号状态显示“未开通”。点击对应学生的“开通账号”，填写并确认初始密码即可；发现历史账号关联冲突时，由管理员先核对原账号，不要重复创建或猜测密码。
- 修改姓名会同步账户姓名；修改学号后，学生需用新学号重新登录，原有成绩仍属于同一学生。调整班级请使用“调整班级”，保留原班学籍记录。
- 停用学生会同时停用已开通的账号，并撤销已有登录会话；恢复学生时同步恢复该账号。停用学生须先恢复后才能首次开通账号。
- 彻底删除仅适用于没有考试、答卷、成绩等业务记录的停用学生。未使用且由上述流程创建的纯学生账号会一并关闭，账户行保留供历史追溯；历史账号、混合职责或业务关联不允许自动删除。

## 使用考试工作区

1. 打开“考试”，在目标考试行点击“工作区”。
2. 顶部核对考试名称、科目、年级、状态、负责人和总体进度。
3. 使用工作区内部导航完成试卷、题目与 Rubric、采集、处理、阅卷、质量、成绩、申诉和报告工作。
4. 工作区地址包含当前考试。刷新页面或复制地址到新窗口后，仍会打开同一场考试。
5. 页面出现黄色提示时，已加载的数据仍可使用；按提示重试或处理缺少的业务信息。整页错误时点击“重试”，不要重复提交正在保存的表单。

## 常见问题

- 看不到某个菜单：菜单按角色与权限显示，请联系机构管理员核对岗位角色。
- 学生导入失败：本批不会部分写入。下载错误表，修正学号、姓名或班级代码后重新导入整份名单；与已有学生完全一致的记录会跳过。
- 创建用户提示用户名已存在：同一机构内用户名不可重复，请更换用户名。
- 工作区显示“年级待确认”：先确认考试已选择班级，并检查年级、班级数据是否完整，然后刷新工作区。
- 页面提示数据暂时不可用：其他已加载区域仍可操作，可稍后点击顶部刷新按钮重试。
