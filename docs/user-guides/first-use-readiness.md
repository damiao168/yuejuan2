# 首次启用与系统准备情况

平台管理员首次登录后会看到“首次启用”。这里汇总系统核心状态、第一所学校、AI 阅卷模式和数据处理策略。只有系统核心状态、平台管理员账号和第一所学校属于阻断项；AI 未启用或暂时不可用时，系统仍可使用人工阅卷。

创建学校时需要同时创建第一位学校管理员。请通过安全渠道交付账号和初始密码，并提醒管理员首次登录后修改密码。

学校管理员登录后进入“学校初始化”，依次准备学校资料、年级与班级、学生和教师账号。完成这些基础项目后学校即可使用；第一场考试是推荐下一步，可以稍后从工作台创建。

所有进度都来自当前真实业务数据，不保存在浏览器中。刷新页面、重新登录或更换设备不会丢失进度。如果准备情况暂时读取失败，工作台仍可访问，并会提示稍后重试。
