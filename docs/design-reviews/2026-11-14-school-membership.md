# 学校会员中心与试行定价

会员中心面向学校管理员。页面帮助学校比较教师席位、阅卷量和服务内容，并生成可转交采购的参考报价。首版用学校年费和答卷额度描述套餐，校方通过合同和对公转账采购。

## 参考依据

- ZipGrade 将每月 100 份的免费额度与预付一年区分，适合参考低门槛试用和手动续费。它主要面向单个教师的答题卡扫描，其 $6.99 年费对应的服务范围更小。[ZipGrade 定价](https://cloud.zipgrade.com/pricing/)
- Gradescope 将机构采购引导至商务团队，并按机构场景提供评分和评估服务。学校档采用合同价，预留统一部署、交付与支持成本。[Gradescope 机构定价](https://turnitin.gradescope.com/pricing)
- 百炼模型价格按输入和输出 Token 分列，阶梯、区域、模型与缓存策略都会影响成本。学校现有受管模型配置可以接自有 Key，模型服务费按供应商账单结算。[阿里云百炼模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)

## 试行报价

| 套餐 | 软件参考价 | 教师席位 | 答卷额度 |
| --- | --- | --- | --- |
| 试用 | ¥0 / 30 天 | 3 | 试用期间 500 份 |
| 教研组 | ¥1,980 / 年 | 10 | 每订阅年 6,000 份 |
| 学校 | ¥9,800 / 年起 | 标准报价 100 席 | 标准报价每订阅年 50,000 份，具体以合同为准 |

席位按已启用的教师账号计，学生查询不占席。答卷按同一学校的考试、科目和学生的首次成功导入计一次，多页属于一份。重传、复核和失败导入不新增份数。匿名阅卷应采用最终归属后的考生答卷标识，避免无姓名或换页导致重复计量。试用和订阅年的额度对应各自有效期。

建议采用年费预付、主动续费。学校档可在同一合同内增加席位或答卷额度。超额先通知管理员，再由学校选择扩容。已有购买安排按原合同执行。首版价格是可调整的试行参考值，在正式报价前用实际学校的答卷、支持工时和基础设施成本核对。每校的核算至少包含存储、计算、运维、培训以及模型或 OCR 的代付成本。

会员年费覆盖软件权益和约定支持，学校自带模型 Key 的推理费由供应商结算。学校如需平台代付，可在取得真实用量样本后再单列预付额度与结算条款。现有 `model_usage_ledger` 用于用量观测，与学校会员权益计量属于不同记录。

## 首版操作和后续收费条件

学校管理员从设置进入会员中心，可对比套餐并复制或下载参考报价。页面提供采购前确认的信息。当前合同价格、开票、收款和续期仍由双方确认，页面没有已购套餐、余额或订单状态。

若后续开通线上支付，先完成商户配置、确定正式套餐和合同条款，再由服务端创建订单并冻结金额与方案。通过已验签的支付通知或主动查单更新订单，同一订单仅发放一次权益。退款按原订单对账。首版采用手动续费，因此无需代扣能力。[微信支付成功通知](https://pay.wechatpay.cn/doc/v3/merchant/4012791882)、[退款通知](https://pay.wechatpay.cn/doc/v3/merchant/4012791886)

正式计量应采用与业务成功写入一致的去重键，采用只对新合同生效的版本化权益配置。开始收费前再实现订阅有效期、真实使用量、订单和权益校验。学校应能在服务期结束时查看既有数据及采购相关信息，续费约束只针对新增使用。

## 实现与验收

首版入口为学校管理员的“设置 → 会员中心”，地址 `/admin/membership`。菜单和深链接共用角色判断；平台管理员、教师和机构角色不能进入。报价复制失败时提示下载，下载内容与页面共用套餐数据，不带学校或登录信息。

会员页面及相关路由、权限测试共 56 项通过，相关文件的格式检查通过，管理端生产构建通过。已有 `check:production-routes` 门禁在教师答卷原图路径的静态匹配处失败：当前工作区已将路径计算提取为 `answerPreviewPath`，门禁仍匹配原内联表达式。该项没有计为通过，会员中心未修改这段教师逻辑。

2026-11-14 已更新本地 API 和管理端镜像，先完成停写备份，再将数据库从 `000229` 迁移至 `000232`。更新后 18 个项目容器恢复，健康检查、管理端、学生端和会员入口的 HTTP 检查通过。会员入口的 HTTP 200 只证明页面可达；浏览器另行确认未登录时显示登录页，未以此替代登录后的页面验收。当前浏览器没有学校管理员会话，登录后的显示仅由组件和权限测试覆盖。本次部署的安全摘要保存在本地 `output/assistant-membership-20261114/deployment-summary.json`，私有配置和数据库备份不提交仓库。
