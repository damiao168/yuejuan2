## 主要实现位置

- 冻结复核：[有效评估事实](../../services/api-gateway/internal/paper/readiness_assessment_facts.go)、[确认事务](../../services/api-gateway/internal/paper/store_postgres_configuration.go)。未落库默认配置采用数据库实际物化规则；模板缺失给出准备阻断项，继续返回其他检查结果。
- 教师操作：[离线工作台](../../apps/desktop-client/src/components/OfflineWorkbench.tsx)、[任务筛选](../../apps/web-admin/src/features/grading/workbench/taskPaging.ts)。图片恢复不替换评分依据；版本变化需核对，保留总分与评语、重新填写评分点。
- 平台配置：[角色绑定](../../apps/web-admin/src/pages/PanelModelBindingsSection.tsx)、[模型页](../../apps/web-admin/src/pages/PlatformModelConfigPage.tsx)。读取失败与成功读取空绑定分别处理；保存期间的重绘前排队动作也受同步保护。
- 学校预览：[学生预览窗口](../../apps/web-admin/src/features/score-management/components/StudentScorePreviewDialog.tsx)。成绩重试保留所选学生；名单读取失败单独重试名单。

- 学生版本：[学生复盘与申诉](../../apps/student-portal/src/App.tsx)、[图片复盘](../../apps/student-portal/src/features/questions/AnswerReview.tsx)、[会话草稿](../../apps/student-portal/src/appealDrafts.ts)、[发布版本比较](../../services/api-gateway/internal/scorerelease/student_release_version.go)、[批注事务](../../services/api-gateway/internal/reviewannotation/store_postgres.go)。四路证据请求都绑定预期发布；题目和批注冲突关闭原申请入口。图片错误事件无法取得 HTTP 状态，因此重新请求同版题目复核，仅明确的版本冲突才要求重新核对；复核期间暂停提交，普通坏图或网络错误保留文字申请能力。

## 能力边界

本轮没有提交、推送或部署。浏览器回归使用 API 夹具；单元测试和 SQL 脚本驱动测试不能替代真实 PostgreSQL 并发集成验证。未配置数据库验收连接时，数据库验收不计为通过。

学生会话草稿仍不是永久保存，旧版草稿不会自动复制到新版表单。后端仍允许窗口内的合法旧版申请；本轮保护的是界面证据与申请依据的版本对应。图片在后端发现版本冲突时不会返回新版二进制。已经完整读取同版证据后才发布的新版本，不使既有同版证据变成另一版。
