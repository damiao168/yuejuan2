# 各身份前端布局优化与业务边界核实

## 三项核实结果

### 两套成绩发布

旧考试发布流程在同一事务内公开并锁定 submission_grade、锁定 final_grade，并把考试标为 published。旧学生成绩查询读取这套结果。成绩版本发布流程更新 score_release_current；独立学生门户读取该指针。二者影响不同读端，旧考试发布不是门户版本发布的硬前提。

版本号表示创建顺序，不能代替当前门户版本。较早创建的草稿可以在较新版本之后发布，成为门户当前版本。前端现读取 current-published 接口，并在发布早于当前版本的草稿时提示版本号将变小。

证据：[旧成绩事务](../../services/api-gateway/internal/score/store_postgres.go)、[版本发布事务](../../services/api-gateway/internal/scorerelease/store_postgres.go)、[门户读取](../../services/api-gateway/internal/studentportal/store_postgres.go)、[前端读取与测试](../../apps/web-admin/src/features/score-management/hooks/useScoreWorkspaceData.test.tsx)。界面把两个入口并列展示，不用步骤编号暗示必然先后关系。

### 草稿保存

| 工作区 | 已有保存能力 | 本次处理 |
| --- | --- | --- |
| 题库 | 点击保存后写服务端；未保存题干、评分规则只在表单 | 切题库、题目、版本、类型前确认；站内离开与刷新提示 |
| 模板 | 点击保存后写服务端，按 revision 校验 | 未保存时禁止锁定；切试卷、模板、刷新前确认；冲突保留本地画布；保存/锁定等待期间冻结名称与区域编辑 |
| 阅卷 | 约 1200ms 后自动写服务端；失败回退仅在内存 | 只把服务端确认成功称为已保存；未同步内容离开前提示 |
| 仲裁 | 提交最终分、说明与反馈时写服务端 | 切任务、筛选、刷新和站内离开前确认；提交期间冻结编辑与任务切换，失败保留内容 |
| 申诉 | 教师意见或管理员结论提交时写服务端 | 同上；重新分派前确认放弃未提交结论；提交中保护当前任务 |
| 三智能体角色绑定 | 点击各角色保存后写服务端 | 标出未保存角色；切范围、学校、标签及站内离开前确认 |

[统一导航保护](../../apps/web-admin/src/router/useUnsavedChangesGuard.ts)覆盖路由导航和前进后退；浏览器刷新/关闭使用 beforeunload。提示不等于持久化，也不保证浏览器崩溃或会话失效后恢复未保存内容。成功保存的服务端版本仍是恢复依据。

### 平台统计

平台学校服务在分页前对授权范围内的筛选结果计算 summary.total/active/disabled；已有 limit=1 测试证明汇总不只覆盖当前页。工作台分别按 model_health=warning/unconfigured 获取 summary.total，可展示这两类学校的全量筛选数。单行 attention_reasons 不提供全量异常聚合，界面不把前 50 所学校外推为全平台异常数。

证据：[服务](../../services/api-gateway/internal/platformschools/service.go)、[分页与汇总测试](../../services/api-gateway/internal/platformschools/service_test.go)、[平台工作台](../../apps/web-admin/src/pages/DashboardPage.tsx)。
