# 学校管理员统一 AI 对话实施说明

日期：2026-10-02（北京时间）。本说明替代固定查询页面方向；当前实现不引入 MCP。

## 产品与执行链路

管理员在同一对话中提问、追问或请求写作。模型根据受控工具定义选择调用、追问或直接回答，真实工具结果回到模型后继续规划，最后输出自然语言回答。页面显示查询进度、来源及处理入口；没有业务/通用切换，也没有必选任务。

考试上下文是可移除提示。名称由服务端获准读取；多候选时追问，来源不完整时明确限制。历史回答与附件是会话材料，不是本轮已核实事实。

## 已实现的首批能力

| 能力 | 真实来源与边界 |
| --- | --- |
| 查找考试 | AccessScope 下有限分页查找，名称/科目/创建时间过滤；不冒充全量或举行日期 |
| 读取进度 | 与原页面共享 workspace 服务；未知业务问题保留，来源故障不变零 |
| 学生端发布诊断 | 完整 releasegate Inspect 与当前发布指针；不写发布证据、不发布 |
| 一般问答与写作 | 同一模型及对话入口，无需业务工具 |
| 连续追问 | 内存保留单一实际考试上下文，下轮重新授权和读取；多场比较不默认选最后一场 |

## 稳定维护边界

`SchoolConversation` → `ConversationService` → `AgentModel` / 业务工具注册 → 已有领域服务。

模型接入复用当前租户配置和密钥解析，新增原生工具协议适配，不放开客户端 system/tool 角色。无业务数据的探针单独验证工具格式；成功短暂缓存，不兼容时明确报错，不退回固定查询。规划与最终回答均计入用量，每次调用独立去重键，关联同一 turn。

每个工具声明稳定名称、描述、参数 schema、权限及执行函数；真正授权发生在每次执行。新增模块接入窄读服务；权限目前在 HTTP handler 中的模块应先提取共同查询层。成绩比较需要只读一致口径 bundle，不能通过会写记录的 Export 获取数据。

MCP 未来只作为同一工具执行层的外部适配，不代替模型选择、业务授权或领域规则。菜单标题、顺序和布局通常不影响工具；业务语义、权限或字段改变时必须更新适配及回归验证。

## 当前限制与后续范围

当前首批工具尚未覆盖成员、题库、老师任务明细、成绩分析、申诉与审计。后续按各模块授权读能力增加工具，不扩大模型权限、不复制业务规则。业务写入另行设计确认、幂等与正式门禁。

对话预算为 4 轮规划、6 次业务工具、3 分钟请求；单工具结果最多 64 KiB。各来源分别读取，未冻结同一跨服务快照。业务会话仅在页面内存保留，普通个人设备历史按完整授权指纹隔离。

## 验证边界

脚本模型与 HTTP 替身用于验证工具选择链路、实际来源回传、权限拒绝、角色伪造、调用预算、取消、来源状态及用量关联；不作为外部模型回答质量保证。前端验证请求归属、来源与范围处理、授权变化、业务会话不落盘；实际供应商兼容性以配置和运行时探针为准。
