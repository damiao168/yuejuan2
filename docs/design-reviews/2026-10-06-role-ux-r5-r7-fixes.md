# 四角色产品复审 R5–R7 修复与验收

本轮承接 [R1–R4 修复](2026-10-06-role-ux-r1-r4-fixes.md)后的复审，按 R5、R6、R7 拆分，三个智能体并行实施并交叉审查。对比以本轮开始时的工作区备份为基线，保留已有未提交修改。本文只记录本轮三项问题，不能替代四角色全产品验收。

## 用户行为变化

| 编号 | 身份、原问题 | 修复后的行为 |
| --- | --- | --- |
| R5 | 学校管理员：数学简答、计算题的默认评分证据包含学科不支持的类型，直接保存被后台拒绝，阻断后续冻结 | 新配置的默认值与可选证据均取学科模板、题型原型的交集。切换学段、学科、模板或题型会更新可选项，清理失效选择并提示重新核对；缺模板、空交集、无选择或非法证据不能保存。保存处理再次按提交值校验，不只依赖按钮状态 |
| R6 | 学校管理员、阅卷教师：客观题默认评分模式被学科的 AI 默认覆盖；保存后实际转人工，固定规则不能自动执行 | 未配置题目的评分模式采用题型原型默认；双评、盲评默认采用双人独立评分。父级传递当前考试的阅卷方式。已有配置和冻结快照优先，管理员显式选择客观题 AI 模式时保留选择，并明确提示实际转人工及固定规则不执行 |
| R7 | 学生：题目或批注已返回成绩版本冲突，另一路请求仍挂起时，页面持续等待，没有恢复入口 | 任一路确认版本冲突就立即结束本题加载，隐藏旧证据及复核表单，显示“查看当前成绩并重新核对”。另一路迟到成功或普通失败不能恢复旧证据。明确重新核对后才读取当前成绩；旧版草稿仍按发布版本隔离，不自动复制到新版 |

评分配置读取失败、尚未完成或已切换上下文时不能保存。关闭重开、题目 A→B→A、校验中切换考试、旧保存返回都受窗口代次保护。保存失败保留选择供重试；保存请求已经发出时，关闭不能撤销后台写入，因此当前窗口等请求结束再关闭。换题或换考试会丢弃旧响应对新界面的更新，不代表撤销已发出的请求。

冻结快照和已保存的证据保留原值；编辑时若现有选择已不兼容，会提示并要求重新选择，查看配置时仍展示历史选择。默认模式不会批量改写已保存的 AI 或人工策略，R3 高风险开放题的既有禁止组合仍被拦截。既有 `coding` 等题型到原型的映射保留，本轮没有统一所有前后端映射；默认模式对当前选定原型生效。

学生端切题、收起、卸载或重新核对后，旧请求不能影响当前页面。普通批注失败仍提供单独重试；普通题目失败保留重新加载入口。复核提交期间禁止会卸载表单的当前成绩重载，既有同步提交状态也在回调处核对。

## 验证结果

- 管理端统一专项：8 个文件、93 项通过，覆盖新配置、评分默认、准备冻结、父级题目页面及编辑状态。初次与生产构建并行执行时，两个原有页面测试触及 5 秒超时；构建结束后以单 worker、15 秒单项超时重跑，93 项全部通过，没有改动这些测试或全局门槛。
- 新增配置组件 23 项、默认模式 helper 24 项包含在上述 93 项中；独立交叉回归同样通过，不累计为额外总数。组件测试使用表单替身，不能替代真实 Ant Design 验收。
- 学生端全量：11 个文件、128 项通过，其中新增即时冲突恢复 11 项。覆盖题目/批注先冲突且另一请求挂起、迟到成功/普通失败、切题/收起/卸载、旧草稿与新版隔离、普通失败重试及提交中禁止重载。
- Chromium：5 个场景通过，真实管理页面与 Ant Design 表单运行，覆盖数学简答、计算题、普通选择题、双评选择题、盲评选择题。检验未配置时禁止冻结、跳转配置、合法证据与模式的 PUT、保存提示、准备核对显示的模式、确认请求的配置 hash 以及成功界面。
- Go：`grading`、`assessment`、`paper` 三个包通过。新增配置→冻结→评分路由测试含 8 个子场景，使用真实内存配置存储的保存及冻结方法，再调用实际评分路由；检查普通客观规则模式走 OMR/规则路径，双评及显式人工模式保持人工，显式客观 AI 模式仍按不支持原因转人工。
- 管理端和学生端 TypeScript、生产构建通过；管理端生产路由及构建体积预算通过。用户可见文案、适用源码的 Biome 错误检查、Go 格式检查及生成契约检查通过。注册路由仍为 524 条：276 条 OpenAPI、248 条已审核遗留缺口。构建保留既有大包提示，学生既有 NaN 展示夹具仍输出 React 警告；未调整门槛。

浏览器使用 API 路由夹具，冻结成功由夹具模拟；它验证真实界面与请求，不验证后台冻结事务。Go 新测试使用 MemoryStore 与真实路由组合，不验证 PostgreSQL 冻结事务、默认物化 SQL 或正式评分作业。真实数据库完整端到端流程未运行，不能计为通过。
