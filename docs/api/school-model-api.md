# 学校模型 API 与考试资料识别

平台管理员在“模型配置”中选择学校，填写供应商、接口协议、Base URL、API Key、模型名称、模型版本和服务区域。可以创建多个配置，在用途列分别勾选“对话”，同时开放多个供应商；学校管理员在聊天页选择本次使用的模型。

- 对话开放范围独立保存。新增开放项要求模型已启用、已配置密钥且文本回复检测通过；已开放项停用后保留勾选，但不能调用。每次新请求重新检查开放范围和可用资格。
- 默认配置仍为单选，与对话开放范围分开。考试资料解析可独立指定模型，也可跟随默认配置；两种外部解析配置都要求当前结构化检测通过。图片预处理和文字 OCR 仍由本地 Worker 执行。
- 解析选择外部模型后，资料中的文字会发送到指定供应商。页面在保存前显示这一用途。
- 解析跟随聊天且未选择外部默认项时沿用本地模型；已明确选择的解析模型或聊天默认项停用、密钥不可读或缺少必要能力证据时返回失败，不静默切换供应商。
- 主观题评分仍遵守原有模型治理、评测和教师复核流程，不因资料解析 API 分配而切换。
- 密钥在 PostgreSQL 中通过 AES-GCM 加密，只返回掩码。网关仅在向已鉴权的内部解析服务发起请求时传递解密后的密钥；密钥不写入任务结果或模型提示词。

## 接口

平台模型配置接口要求平台管理员身份；读取列表使用 `model:read`，保存、删除和探测使用 `model:managed_api:manage`。路由也兼容 `model:config:manage`，具体学校范围仍由服务端校验。

获取模型列表和使用同一密钥添加模型时，`credential_source_id` 必须指向同校、同供应商、同一 HTTPS 域名和端口的启用配置。只调整 API 路径时可继续使用已保存的密钥。来源配置已停用时返回 HTTP 409 和 `managed_model_credential_source_disabled`，提示先启用来源配置，不再误报为地址不安全。编辑页禁用停用来源的模型列表查询并显示启用路径；输入新 API Key 后可查询，编辑保存仍保留配置原有启停状态。模型名称可以手工填写；修改模型名称等连接信息时，保存前仍须通过连接校验。

编辑配置时 API Key 留空表示保留原密钥，同域名、同端口修改路径无需重填；更换域名或端口时必须显式输入 Key，可以使用原密钥，无需重新申请。后台不会自动将已保存密钥发送到不同域名或端口，缺少输入时返回 HTTP 400 和 `managed_model_credential_origin_changed`。修改路径后仍按新地址重新检测，原有文本和结构化能力证据不能直接沿用。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/platform/model-api-configs?tenant_id=...` | 查看学校配置，不返回密钥 |
| GET | `/api/v1/platform/chat-model-access?tenant_id=...` | 读取该校对话开放模型与修订 |
| PUT | `/api/v1/platform/chat-model-access` | 保存 `tenant_id`、`expected_revision` 和完整 `model_ids` 名单 |
| GET | `/api/v1/ai-chat/model` | 学校端读取当前默认选择及已开放模型，只含公开名称和可用状态 |
| POST | `/api/v1/platform/model-api-configs` | 创建配置，正文包含 `tenant_id` |
| PATCH | `/api/v1/platform/model-api-configs/{id}?tenant_id=...` | 编辑配置，密钥留空表示保留 |
| POST | `/api/v1/platform/model-api-configs/{id}/probe?tenant_id=...&mode=quick` | 快速连接检查；省略 `mode` 也使用此模式 |
| POST | `/api/v1/platform/model-api-configs/{id}/probe?tenant_id=...&mode=text` | 普通文本回复检测，不要求 JSON |
| POST | `/api/v1/platform/model-api-configs/{id}/probe?tenant_id=...&mode=structured` | 结构化检测；旧名称 `capability` 仍兼容，有效的既有结果可复用，`force=true` 强制重新检测 |
| POST | `/api/v1/paper-imports/{id}/cancel` | 停止当前识别并保留已上传资料 |

对话开放名单使用修订检查，其他管理员已修改时返回冲突，页面保留原选择并提供重新读取入口。`model_ids` 必须显式传入数组；空数组表示取消全部开放，省略或传入 `null` 会被拒绝。平台管理员的目标学校范围仍由服务端校验。

学校对话请求可携带 `model_config_id`；选定的连接贯穿同一请求中的规划、工具查询和最终回复，供应商失败时不会自动换模型。未传编号时优先选择仍获准且可用的默认配置，再选择名单中其他可用模型。浏览器按账户及授权范围保存选择，公共电脑仅在内存保留；当前对话回复进行中不能切换模型，开启新对话后可另选模型，后台旧对话继续使用发起时的模型。全局仍最多同时进行 5 个对话。

快速检查访问 `/models`，确认接口允许列出指定模型。它不发送生成请求，因此不能证明生成接口可用或账户有足够生成额度，也不能替代文本或结构化检测。单次请求默认超时为 8 秒；网络失败最多重试一次，两次请求与等待合计最多 12 秒。

文本检测在 OpenAI 兼容协议下先检查模型列表，再发送一条普通消息，不附带 `response_format`，收到非空正文即通过。它只证明本次请求成功，不查询供应商余额，也不保证后续持续可用。选择学校默认模型以此独立文本证据为门槛。

结构化检测在兼容协议下使用 JSON Object 模式并在本地校验字段结构；要求 `question_no` 为字符串、`max_score` 为有限数字，不再要求题号必须精确写成 `1` 或分值必须等于固定样例。`第1题` 不会仅因表达形式不同而失败。此检测版本为 `structured-json-v4`，只证明最小结构化兼容性，实际资料解析和评分仍需校验各自完整结构并遵守评测、角色绑定和教师复核流程。

DashScope 原生协议固定使用 `https://dashscope.aliyuncs.com/api/v1`，文本和结构化检测直接发送最小生成请求；原生结构化检测采用提示词约束并在本地校验返回 JSON，不把它标为供应商 JSON Schema 保证。生成阶段单独使用 60 秒超时，覆盖等待响应头和读取完整正文；客户端取消请求仍会中止检测。文本和结构化请求可能消耗供应商额度，生成失败后不自动重试。

连接、文本、结构化三类状态独立保存。快速检查不会改写文本或结构化证据；结构化校验失败但已收到非空正文时，可以更新文本成功证据。超时、暂时不可用、限流及其他暂时性供应商故障不能证明能力不支持，因此保留此前成功证据；本次失败仍会显示在探测回执中。未收到供应商用量时，返回的零值不代表实际扣费为零。

解析请求使用当前学校保存的解析用途设置：`model` 使用独立模型，`follow_chat` 跟随聊天默认项，未保存用途设置时按 `follow_chat` 处理。逐请求创建模型适配器，不修改共享全局模型。只有文本证据的默认模型可以聊天，跟随它解析会返回缺少结构化验证的错误；独立解析模型不依赖聊天默认项。兼容协议解析使用 JSON 模式并在本地严格验证结构；供应商仍须支持 JSON 模式和足够长的输出。

## 数据迁移

`000187_managed_model_text_evidence.sql` 在 `000186` 之后执行，增加 `last_text_status`、`last_text_message`、`last_text_tested_at`、`last_text_usage`、`last_text_diagnostic`，并扩展探测模式约束。文本和结构化状态均使用 `untested`、`success`、`failed`；没有文本用量或诊断时对应 JSON 列允许为空。

迁移将任一旧版本的结构化成功记录回填为文本成功，保留已证明可以生成回复的学校默认模型；只有 `/models` 成功的记录不会回填。旧结构化版本原样保留，不能自动获得 v4 评分、评测、解析资格，需要重新做结构化检测。迁移同时替换评分角色健康投影和评测候选触发器中的版本守卫，并刷新角色健康投影；历史迁移文件不改写。

`000188_document_model_selection.sql` 在 `000187` 之后执行，新增学校解析模型用途及修订。保存时携带读取到的 `expected_revision`，并发修改返回冲突；切回跟随模式同样需要核对修订。已被独立解析用途引用的模型不能删除。

`000192_chat_model_access.sql` 新增按学校隔离的对话开放名单及修订。`000193_chat_model_access_backfill.sql` 将存量学校原默认配置保存为初始开放项，不自动开放其他已保存密钥的模型，也不覆盖已保存的名单或空名单。后续修改、停用或清除默认配置不改变已保存的对话开放范围。

## 任务状态

页面展示页面预处理、文字识别、AI 内容解析的阶段进度，百分比为阶段指示。轮询临时失败后自动恢复；轮询期间不卸载页面。无题目、答案、解析或评分标准的资料显示“未识别到考试内容”，保留重新识别和手动补充入口。

停止后任务状态为 `cancelled`，后续到达的结果不能覆盖停止状态。重新识别复用已上传资料。
