# 管理员数学图片导入：多模态直读设计与验证

日期：2026-09-16。范围：双栏、公式密集、题目/答案/解析混排的数学试卷图片。

## 结论

这类图片不再把传统文字 OCR 和公式 OCR 当作主识别链路：

- PNG、JPEG、WebP 原图直接交给学校配置的多模态模型。
- 扫描 PDF、TIFF 只使用页面 Worker 渲染成图片，随后直接交给多模态模型。
- 可直接提取正文的 Word、文本 PDF 仍使用文本解析；与图片混合上传时，文本和原图在同一次结构化解析中合并。
- OCR、公式 Worker 的旧接口仅用于历史任务兼容，新图片导入不会调度这些任务。

这不是“换版式后重新训练”的方案。版面、公式、题号和噪声由通用视觉模型按原图理解；本地代码负责文件边界、来源绑定、结构校验、幂等、人工复核和结果入库。

## 为什么旧结果不准

旧流程先把原图压成 OCR 文本，再让后续逻辑理解已经损坏的内容，因此出现：

- 上标、平方、分数、绝对值和集合条件竖线丢失；
- 双栏阅读顺序错乱，题干、答案、解析串行；
- 页眉、页码和右下角“公众号·宇桐资料分享”进入正文；
- 类型置信度被误读为逐字准确率；
- OCR 或公式 Worker 故障会阻断整份资料。

这些问题不是再叠一层规则或训练固定版式能根治的。OCR 仍适合清晰印刷文本、全文检索、坐标定位和低成本批处理，但不再作为复杂数学页面的内容事实来源。

## 已实现

- 原始页面以受校验的图片数据发送给学校当前选择的多模态模型；配置为 `deepseek-flash` 时由当前 DeepSeek V4.1 Flash 处理。模型提示明确要求保留上下标、幂、根号、分式、`|`、绝对值、集合条件竖线、无穷和区间端点。
- 题干、选项、答案和解析字段使用 Markdown，公式使用 `$...$`/`$$...$$` LaTeX；管理端通过禁用原始 HTML、外链和外部图片的 Markdown + KaTeX 阅读视图展示。原文编辑框默认隐藏，通过每题右侧按钮按需展开，避免内容重复。
- 明确排除学校/考试页眉、页码、公众号、水印、资料分享署名、二维码和装饰文字。
- 图片无分值或评分细则时保持 `null`/空数组，禁止补写。
- 页面引用与租户文件、文件哈希、来源 ID、文档序号、页码绑定；模型不能伪造来源。
- 单页最大 8 MiB、单次原始图片合计最大 32 MiB，内部请求上限 48 MiB。
- 页面引用持久化到不可变解析输入；新增 schema `000152`，重启和重试不会丢图。
- 模型只返回精简视觉协议，服务端补全候选 ID、可信来源字段、解析步骤和评分结构；模型侧 Schema 字符数从 9152 降为 4244（减少 53.6%），多模态输出上限从 16384 收紧为 8192。原图仍使用 `detail: original`，不以降低清晰度换成本。
- 固定提示和 Schema 放在图片之前，以利用 DeepSeek 自动前缀缓存；供应商返回的输入、缓存命中、输出、推理及总 Token 写入 `paper_import_job.model_usage`（schema `000153`）并在核对面板展示。费用仍以供应商账单为准。
- DeepSeek V4.1 Flash 默认开启高强度思考；结构化转录请求对官方 DeepSeek 端点显式发送 `thinking: disabled` 与 `reasoning_effort: none`，避免为抄录任务支付隐藏推理 Token。其他 OpenAI-compatible 厂商不注入 DeepSeek 专用参数。
- 兼容 OpenAI-compatible 服务给 JSON 增加 Markdown/短前缀的情况：仅提取一个完整 JSON 对象，之后仍执行完整 JSON Schema 和业务来源校验。
- 完成后的结构化 JSON 随 Worker 任务结果持久化；离线测试使用人工核准的期望样本 `ai-services/tests/fixtures/expected_multimodal_math_paper.json`，后续测试不消耗模型 Key。该样本不是 DeepSeek 的真实返回，不能作为供应商准确率证据。

## 实际验证

- 旧 OCR 基线：7 道题、7 个答案、6 份解析、31 项问题；存在 `σ2`、`21nx`、`+∞0`、竖线丢失和公众号污染。
- 新链路真实调度已确认直接进入 `paper_parse / visual_model`，总页数 1；未创建 `layout`、`ocr` 或 `paper_formula` 任务。
- 实际供应商响应暴露了两项兼容问题并已修复：JSON 外层包装、视觉引用中的 `file_asset_id/document_index` 为 `null`。这两个字段现在由网关可信元数据回填，再做严格校验。
- 用户要求停止付费调用后，测试任务已取消；当前活动 `paper_parse` 任务数为 0。没有继续请求模型。
- 离线 JSON 回放验证：7 道题和答案顺序为 `B/C/D/A/D/A/B`；保留集合竖线、`σ^2`、`2\\ln x+x^2-ax`；结果不含公众号或“宇桐资料分享”。
