# 答题卡区域建议、审核与诊断

区域分析自动生成可编辑草稿。多模态识别的题号、题型、类别与几何一致时，系统直接对应正式题目；教师发现错误再修改，不需要逐框点击确认。页面线框只说明可能存在边界，不能单独证明类别。只有未关联、重复题号或内容冲突等实际问题需要纠错，保存草稿与最终锁定仍是不同操作。

提示词、视觉证据与按需裁图的研究设计见[多模态优化资料与方案](answer-sheet-multimodal-optimization.md)。该文区分 v6 兼容基线、v7 自动对应与尚待实施的局部模型复核，固定响应回放不能作为真实模型效果或新提示词已上线的依据。

## 识别与重试

Python 先按模型输出做题号、类别和身份字段的一致性检查，再精修边界、排除有充分证据的独立禁止作答区，最后只对仍可见的候选计算空间冲突；局部填空补框在这一步之后追加，并跳过已经排除的说明区。整页静态 OCR 每页最多一次，使用中文和英文标签；选项结构、条码解码或贴码区标签分别提供辅助证据。OCR 未读出不否定已经一致的多模态识别；明确反证才降为 `needs_review`。`supported` 表示结果通过当前自动使用规则，不表示独立 OCR 已证实，更不表示识别绝无错误。只有条纹不能证明条码，空白贴码区也不要求能解码。

模型自报原因最多 32 项，公开结果对其截短前会先扫描全部明确反证并折成固定待核对原因，防止末尾禁区或类别冲突被长度限制丢掉。OCR 不可用、缺失和预算不足等诊断不属于明确反证。英文 Class、School 可用 `identity_fields` 支持对应班级、学校，但 `static_label` 仍为 null，不能把中文译名伪造成实测标签。

整页 OCR 的 TSV 按制表符读取，不把数学内容中的引号当作 CSV 引用字段。超时、进程失败、输出过大和解析失败分别记录固定原因码，不把异常原文或填写文本写进普通日志。

Go 再次检查正式题型、题号及语义状态。旧工作节点缺少 `semantic_check` 时不能直接把类别当作已验证。当前正式切题协议仍是一题一个 ROI，同题多块作为待核对问题保留，不能静默选第一块或跨过别题合成大框。

网关从正式题目快照提取填空题白名单，浏览器不能提交该清单。局部填空发现仅在整页语义调用成功后运行，依据实测分隔线、印刷填空标题、带括号的可信题号和相邻答题横线提出小框，不按题数均分页面。单次局部 OCR 最多两秒，每页最多四次、共同六秒预算，二次重读也计入预算。找不到证据时不补框。小框在边界吸附之后追加，避免再次扩大到包含禁区的整栏。

局部发现输出 `local_detector + needs_review + unassociated`；网关会把类别降为 `uncertain`，前端只在题号唯一对应正式填空题时显示“填空第 12 题 · 待核对”，不写入 `question_id`，也不算题目覆盖。模型原来的未知大框与局部小框可同时保留，并解释二者关系，教师须核对用途和边界。

同排小框的画布徽标简写为“12题·待核对”，完整说明保留在悬停提示及草稿元数据中。小框横向和底部留出半个印刷题号字高的余量；相邻行需要时裁到共同边界，且始终截在实测分区内。这只能容纳有限的越线笔画，不能保证任意手写扩展均被自动覆盖。

前端按成功页替换旧的未确认自动建议。合法空成功清除该页旧自动建议；请求失败或整批疑似均分伪框被拒绝时保留旧结果。人工编辑、人工确认及缺少来源元数据的历史区域受到保护。异步结果提交时读取当前编辑状态，来源、版本或题目范围改变后丢弃旧响应。

整页模型成功、局部填空检测失败属于部分成功。前端显示顶层固定局部失败码，继续更新模型建议，仅保留同源且带填空证据码的旧本地待核对框。新同题或同范围结果优先，人工区域仍优先；下次局部检测成功后恢复正常替换。局部候选合并时跳过 `instruction` 和 `other`，避免补框的重叠检查把已排除的禁止作答牌重新变成待核对区域。这个例外不保留旧模型误框，也不把未知失败原文显示给教师。

## 状态与确认

`origin` 记录 `model`、`local_detector`、`library` 或 `human`，人工拖动自动框不会抹去原始来源。`review_state` 分别为 `suggested`、`edited`、`confirmed`、`discarded`；`confirmed` 保留历史显式确认的事实，但不是所有区域的必经状态。通过校验的 `supported + suggested` 区域可以直接使用，教师编辑或重新关联后的 `edited` 区域也不再要求额外逐框确认。题目覆盖、空间冲突、来源修订和选项几何检查继续执行。

前后端只对完全没有审核元数据的旧区域保留历史兼容。仅带来源或语义状态、却缺审核状态的部分历史记录会在页面提前提示问题，避免显示可确认后才被后台拒绝。人工已修改或确认的事实仍优先。

复用已收录模板的区域保留 `library + suggested + not_evaluated`，不继承人工确认或伪造本次模型校验事实；通过同校、正式题型、完整覆盖和几何检查后可直接使用。明确带有 `needs_review` 的库区域仍须纠错。

未关联候选、未完整对应的选择题大区及丢弃记录存入 `layout.editor_state`，其 `source_sha256` 是原始来源文件摘要，不是压缩后的模型输入图摘要。草稿可以保存未解决问题；锁定、启用及收录模板库要求实际问题解决，不以缺少逐框人工确认阻挡正常自动结果。历史无新元数据的区域保持兼容，仍须通过正式题目覆盖及区域冲突检查。候选转换、丢弃、整页替换与确认进入编辑器撤销历史。撤销/重做只保留当前编辑会话的最近 50 步，重新加载模板后清空历史；跨刷新恢复的是已保存的当前候选与丢弃记录。

最终确认先保存当前布局，再使用保存返回的修订号锁定。确认弹窗打开后布局发生变化时，原弹窗不能锁定用户尚未同意提交的另一份布局。

待核对和未保存分别判断。候选已经随草稿保存时，刷新、离开及切换来源不应提示放弃未保存内容；候选新增、移动、丢弃或转换后尚未保存时，仍须提醒。最终确认和模板库收录继续检查待核对内容，不因草稿已保存而放行。

## 诊断留存

`template_analysis_diagnostics.py` 为每次分析建立运行记录，将请求 ID、来源显示图摘要与尺寸、可信模板修订及原文件摘要、正式题目快照摘要、提示词/schema/算法/语义版本连接起来。解析前保留已收到的供应商助手响应；解析失败与处理异常也记录失败状态。供应商没有返回实际版本时不推断该版本。

普通日志只含有界元数据。原始助手响应需显式启用 `EDUGRADE_TEMPLATE_ANALYSIS_CAPTURE_CONTENT=true`，写入 `EDUGRADE_TEMPLATE_ANALYSIS_DIAGNOSTICS_DIR` 的独立目录；不记录请求认证头、密钥、完整请求图片或 OCR 填写文本。受控原始响应仍可能含模型误抄内容，应限制目录访问，不直接加入 CI。

默认保留 604800 秒、最多 1000 个文件及 268435456 字节，每次运行原文最多 2 MiB。容量或保留时间先到即清理，存储太小时本次记录也可能被清理。只清理模块生成的 32 位十六进制文件名的普通 JSON 文件，跳过符号链接、目录及其他名称；存储失败不阻止用户继续核对草稿。Compose 使用独立命名卷，其他环境默认关闭原文采集。

## 配准、评测及能力边界

v7-evidence 在完整选择题大区内同时返回 `objective_items`：实际印刷题号、每题边界及带字母标签的选项边界。后端与前端验证正式选择题白名单、题号唯一、父子包含、选项数量与标签、重叠及观察题号覆盖；完整通过后直接生成每题和相对选项坐标，不再让教师手工分配题号。不能按阅读顺序猜题号或按数量均分坐标，异常整组保留供纠错。

原“定位填涂格”和“识别题号（参考）”保留为纠错工具。前者测量实际选项格，后者只给数字线索。手动流程仍须声明大区实际包含的题目；八题只发现六组时不能按顺序冒充完整，未覆盖题目继续显示缺漏。

学生页切题前，`page_processing/region_visibility.py` 在模板像素坐标检查每个必需作答区是否落在原图的有效投影内，仅容许半像素取整误差。总体面积覆盖率通过不能替代该检查。没有必需区域时返回 `not_evaluated`，不会冒充可见性已验证；该门禁不能证明模板中漏配的作答区完整，也不能证明语义分类正确。

离线评测入口见 [区域评测说明](../../scripts/evals/README.md)。固定响应回归、真实 PDF 像素上的故障注入与真实供应商调用应分别报告。合成夹具不是历史原始响应，规则测试通过也不是模型准确率证明。

本地 OCR 和选项结构检测有漏检边界，实际未关联或冲突仍需纠错，不能把 OCR 缺失单独当成有效模型结果的人工核对要求。本轮未实现完整的一题多 ROI 协议、任意缺页身份自动恢复、纸张曲面展平或独立标注集上的模型准确率承诺；也未创建夜间自动评测任务。

对于模型明确观察到禁止作答标签、没有作答或身份正向结构的独立小框，v7 将其归为 `instruction`，前端不绘制；不能仅因旧类别是条码就把它保留成橙色未知框。后端和前端都会检查固定的禁区、类别和区域冲突原因码，即使旧结果错误地标成 `supported` 也不得自动对应或锁定；人工 `edited`/`confirmed` 仍表示教师已经处理。大框、混合填空栏或存在实际题号/选项等冲突时不适用此排除，也不按页面固定位置删除。

Tesseract 对“禁止／作答”两行两列标牌仍会漏读。2026-10-18 的同源局部离线对比中，已有 PP-OCRv5 mobile 缓存可识别四字，但文字块按左右竖列返回，直接拼接块字符串仍不能还原整句。独立进程实测冷启动约 18.6 秒、推理约 0.5–0.7 秒、峰值内存约 508 MiB；块级识别分数不能当作单字分数。

可选的 `template_analysis_ocr_runtime.py` 在隔离子进程常驻这套依赖，默认关闭。服务后台预热最多 35 秒，未就绪立即返回；暖请求 IPC 共同受最多三秒限制，超时即关闭通道、终止子进程，回收等待在后台完成，冷却后才能重启。子进程只返回“禁止作答”四字的真实引擎字框、块级分数及全部高分文字数量，不返回其他识别文本。模型从只读目录加载，不回退到下载或业务 OCR 队列；非 root 缓存写入独立临时目录，退出时清理。

`template_analysis_forbidden.py` 在原类别核验之后、填空补框之前检查无题号且未关联的小型未知框。每页最多四个裁图，共享六秒预算；只有四字各一次、没有额外高分正文、字框大小与横排/竖排/两行两列位置关系合理且覆盖候选主体时，才标为 `instruction + supported`。前端不绘制说明区。巨大混合栏、已有题号和关联的作答区不进入此自动排除；缺字、低分、预热、忙或超时均保留原候选。前端仅显示固定中文失败原因，不改变原有填空候选保留规则。

诊断版本中增加 `forbidden_regions`，便于区分旧流程。当前代码及模拟协议回归已覆盖上述规则，但新的隔离子进程与真实 Paddle 字框仍需在目标镜像烟测后启用；此前块级离线试验不能代替该验收，也不能据此宣称自动排除已经上线。
