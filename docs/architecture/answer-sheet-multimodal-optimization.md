# 答题卡多模态识别优化：论文依据与实施设计

研究日期：2026-10-18。本文同时记录研究依据和实现边界。当前源码默认 `v7-evidence` 自动对应策略；部署与真实样本验证须单独记录，不能从源码默认值推断运行版本。学校模型选择保持不变，尚无真实模型 A/B 准确率结论。

本项目为学校阅卷系统。这里分析的是教师上传的答题卡模板，目标是找出身份栏、连续选择题大区、填空及解答作答空间，并自动对应正式题目；教师发现错误再修改，不再要求成功结果逐框人工核对。识别全文、解答试题和读取学生姓名号码不是本入口的目标。整页多模态继续负责主识别，本地 OCR、条码及几何检测提供辅助证据。候选纠错、重试和锁定边界见[区域说明](answer-sheet-region-review.md)。

## 1. 当前代码中需要优化的事实

以下是本轮优化前的代码审查基线，不是论文对本项目的实验结论；第 9 节记录后续实现。

| 位置 | 已核实事实 | 对设计的影响 |
| --- | --- | --- |
| `template_analysis.py::_messages` | v6 已写选择题连续大框、禁止作答不可当条码、不可按整场题号补框等规则 | 不能把重复这些禁令当作已经完成新优化 |
| `template_analysis_schema.py::request_schema` | 请求有 `fill_blank_question_labels`，但主提示词没有解释其用途 | 明确正式填空清单的含义，并解释无独立四边框的填空区域 |
| `template_analysis_schema.py::model_output_schema` | 没有可见题号列表、类别视觉特征或边界锚点 | 模型可返回合法 JSON，却不提供程序能复核的分类观察 |
| `template_analysis.py::_normalize` | 选择题大区的单题标签随后被清空，原始一致性检查已前置 | 群组需要独立的观察题号列表，不能依赖本应为空的单题关联字段 |
| `managed_model.py::_compatible_transport` | 将 `json_schema/strict` 改为 `json_object`，附 schema 文字并在本地验证 | 当前不能声称供应商已经严格约束生成；不要未经核实对所有兼容路由强开 strict |
| `analyzeTemplatePage.ts::createTemplatePageAnalyzer` | 浏览器长边最多 1600，JPEG 质量逐次降至 .4，编码前最多 1 MiB | 小字、细线漏检必须把输入损失作为单独实验变量 |
| `template_page_analysis.go` | 网关整个请求体上限 2 MiB；正式题型清单由服务端提供 | 不能只提高浏览器图片限制；新增输入要一起核对 Base64 膨胀和网关上限 |

当前历史故障包括：15/16 解答区误作选择区、选择区误作姓名/准考证号、禁止作答误作条码、12–14 填空漏检。它们涉及分类、漏检、边界和验收四类问题，不能全部归结为一句提示词写得不够强。

| [DeepSeek Vision 官方说明](https://api-docs.deepseek.com/guides/vision/) | 描述 detail 与内部像素缩放；每张图独立计算视觉 token | 对使用该官方路由的实验，整页加大与拆成局部图分别比较；不能将其他供应商参数套用到这里 |

DeepSeek 文档当前描述 `high` 与 `original` 等价，并描述推理前仍有整体像素预算缩放。因此，保留原输入与模型实际使用多少视觉细节是两个层次。文档没有证明本次漏检就是缩放造成，也不能将某个供应商的像素预算当作通用模型限制。

VEP 论文的完整 PDF 在本次检索工具中因体积超限未载入，已核对 ACL 正式摘要和作者仓库的方法说明；没有据此引用未读表格或报告项目收益。其他引用也没有复制长段原文。

## 3. 优先改版：先观察，再分类，再关联

第一版保持每页一次主调用，先在任务和输出契约里分开职责，不立即把每页拆成多轮请求。这里的阶段是可核查输出的组织方式，不要求模型暴露内部推理过程。

1. 按实际分栏、印刷分区和章节标题检查整页，包括没有候选框的部分。候选只提供几何提示，不能限定可发现的区域。
2. 对每个实际区域报告有限的静态视觉观察，包括标签类别、看到的印刷题号、选项/编号格/条码结构和边界依据。
3. 依据这些观察提出类别；证据冲突或读不清就保留 uncertain，不能擦掉题号来让类别看似一致。
4. 服务端按正式题型核对关联。整场白名单不代表本页必须出现；缺少某题不能成为凭空补框的依据。

提示词规则须覆盖正例，而不仅是反复禁止错误：

| 类别 | 要找的正向特征 | 必须保留的区别 |
| --- | --- | --- |
| 选择题大区 | 多题重复的选项字母/填涂结构，实际可见题号 | 连续选择题用完整大框；章节标题不自动拆区，也不能跨过填空、解答或身份栏强行合并 |
| 姓名/准考证号 | 对应静态印刷标签，或与该字段相符的可靠填写结构 | 选项阵列与编号填写格外观可能相似；页眉位置、矩形或多个小格都不足以单独证明身份类别 |
| 填空 | 正式填空题号、括号编号、作答横线及邻题分界 | 同一大外框内可有多题，没有四边框也要检查；只圈数字或已写答案都会丢可用作答空间 |
| 条码/二维码 | 码图结构，或明确的贴码区静态标签 | 空白贴码区不要求能解码；空矩形本身也不能证明是贴码区 |
| 说明/禁区 | 可读的独立警示标签与该说明块的范围 | 混合外框内有一处警示，不能据此删除整栏作答空间 |

加入少量不含真实学生值的对照示例：同样是矩形，分别展示选项阵列、编号格、填空横线和禁止作答。示例应来自开发集或合成图，避免把故障页真实坐标写成所有模板通用规则。文字反例与图片示例也分开评测，不同时加入后宣称纯措辞收益。

## 4. 模型内部输出增量

建议先扩内部模型输出，公开候选协议和数据库变更另行明确。字段不能只加进 prompt 而不修改严格解析器，否则新增信息会导致整批输出被拒绝。

- `observed_question_labels`：实际观察到的题号列表，与单题关联字段分离；选择题大区仍保留 `printed_question_label=null`。不能把观察列表的允许值限制为正式选择题号，否则 15/16 这种反证会在生成时被排除。
- `visual_evidence`：有限的静态标签枚举、option/identity/barcode 结构枚举、边界类型及可空的锚点框。没有自由文本的学生姓名、号码、答案或条码内容。
- `classification_confidence`：可选的 high/medium/low/unknown，仅作分析；未校准，不能据此确认模板。优先保证前两类字段，不为自报分数增加无效输出。

每份观察区分 `model_reported` 和带运行来源的 `local_detector`。模型引用一个页 hash 只表示来源关联；模型自报“看见标签”也仍可能出错。外部 OCR 没检出字属于未知，不等于该字不存在。

校验在字段清理之前运行，并在人工优先合并之后再查覆盖及冲突。模型把 15/16 观察为选择题、身份区同时报告选项阵列、条码区只有空框或警示标签等情况，应保留矛盾，标待核对。程序不能把模型自报证据标成独立验证成功。

对内部证据字段采用有界枚举、数量和长度限制；锚点必须在当前显示页内并靠近所属候选。隐私值不能通过“证据说明”绕进普通日志。若需要将观察公开持久化，再同步权威接口、SDK 和存储契约。

## 5. 按需局部复核与漏检恢复

局部机制分为两个任务，不能只复核已经画出的框，否则漏掉的填空题永远进不了复核队列。

**类别复核**：针对身份/选择冲突、仅有空框的条码、含警示标签的混合区等，截取有适量上下文的局部图。单独询问可观察的窄问题，例如“是否存在重复选项结构”“是否存在姓名印刷标签”“是否只有独立警示语”。每题允许 yes/no/uncertain；不要先告知“这是条码，请确认”形成诱导。

**漏检恢复**：当本页观察到了填空章节、横线或局部题号，却缺少对应模型候选时，按实际分栏/章节选取较大局部重新发现。正式整场清单缺了 12/13/14 本身不足以确定它们就在本页，也不足以生成坐标。恢复仍失败则显示需要核对，不按题数均分。

保留全页缩略图/分栏上下文与原始高质量裁图的对应关系。裁图必须从更高质量的来源取得，不能将已经缩至 1600 的 JPEG 放大后称为高清。若要从原 PDF 独立重渲染，记录渲染器和旋转，不能声称与原浏览器请求逐字节相同。

裁图使用明确的 `crop_id`、当前来源/修订、整页范围和坐标单位。若局部模型返回裁图归一化坐标 `(u,v,w,h)`，整页裁图范围为 `(cx,cy,cw,ch)`，则转换为 `(cx+u*cw, cy+v*ch, w*cw, h*ch)`；旋转必须在定义裁图前统一，不能直接套未旋转 PDF 坐标。候选最终仍使用 `source_display_normalized`。

一次失败不循环重试整页。先为额外调用设置有界次数、总耗时和用量预算，再用开发集决定具体数值；不能照搬本地 OCR 的三秒超时给远端大模型。超时保留本轮已完成建议与旧人工内容，明确记录未完成的复核项。

同模型第二次调用只是另一观察，不具备统计独立性。符合自动使用规则的结果可以进入可编辑草稿；这不写入人工确认事实，也不自动锁定模板。实际内容冲突、未对应和缺题仍需纠错，人工修改优先保留。

## 6. 路由、分辨率与结构化输出

先记录实际路由支持的能力：JSON 模式或供应商 strict、图像 detail、单图像素处理、图像数及请求体上限。供应商官方能力不等于中转路由已支持。学校当前所选模型保持不变，离线实验不增加教师必须完成的测试图片/配置步骤。

`json_object` 路由继续本地完整 schema、坐标和语义校验，且诊断写明真实模式。只有确认该路由支持当前 schema 后才保留 `json_schema/strict`，不把供应商拒绝 silently 重试成另一种模式。截断必须失败，不能从未闭合 JSON 猜测成功候选。

分辨率实验单独比较当前 1600 JPEG、同渲染来源的较高质量整页、全页加按需局部。除客户端限制外，同时计算 Base64、网关 2 MiB、工作节点和供应商约束。先测效果/成本，再决定修改哪个限制；不能为提高像素无界增加内存和延迟。

临时编号图只作为辅助：保留未标记原图，编号避开原题号与标签；错误候选仍可被拒绝，未标记区域仍可被发现。现有 `candidate_id` 只在 JSON 中传递，不等于已经实施 SoM。

## 7. 对照实验与验收

先冻结提示词、schema、图像字节、正式题型快照和后处理版本。现有 v6 对照使用不变副本，不直接修改评分提示词登记表。模板提示词单独登记版本/hash，并记录供应商实际返回的模型标识；未返回固定版本时如实记录，不能假定别名永久指向同一模型。

| 组 | 改动 | 能归因于什么 |
| --- | --- | --- |
| A | v6、当前 schema、相同请求图片 | 当前基线 |
| B | 仅整理 v7 措辞，schema 不变 | 纯文字规则变化；该版本不得要求 schema 中不存在的字段 |
| C | v7、内部观察字段和交叉校验 | 可核查观察及其校验的整体效果；未经校验原始输出另外保存 |
| D | C 加按需裁图验证/漏检恢复 | 局部视觉输入和额外调用的效果 |
| E | C 仅改整页图像质量/像素 | 输入质量效果；不与 D 同时改变 |

先用当前两页故障样本查回归，每组每页交错顺序重复，避免供应商版本/负载漂移完全落在某一组。后续按来源文档划分开发集和留出集，覆盖不同学校/版式、空白/填写、竖排说明、无独立填空框、分栏与真实条码。当前故障页属于开发样本，不能当泛化准确率。

验收先看模型原始输出，再看固定后处理结果，最后单独报告 OCR/局部恢复的增量。任何一层都不把语义 `completed` 等同于无误或人工确认。

| 指标 | 具体观察 |
| --- | --- |
| 分类 | 分类别 precision/recall；选择区误作身份、禁区误作条码/作答等混淆单列 |
| 漏检 | 正式且本页实际可见的题目召回，单列可读填空题；空白页不补造 |
| 边界 | IoU、真实作答区覆盖比例、右/下边界裁掉面积、包入邻题/禁区面积 |
| 题号 | 观察题号准确率、错误关联、重复/缺题及跨页归属 |
| 可用性 | uncertain 比例、教师修正/删除/补框操作数，避免以全部不确定换低误报 |
| 运行 | schema 有效率、截断、超时、调用数、token/已知费用、延迟分位数 |

两页故障回归要求：15/16 不被确定成选择题；真选择区不被确定成姓名/准考证号；独立禁区不成为可关联作答/条码候选；可读填空区不能仅因外框混合而消失。留出集上线阈值在看结果前确定，按文档汇总不确定性，不能测完再挑有利指标。

## 8. 实施顺序与本次交付边界

1. 先实现可独立切换/回放的 v7 文字版本与版本/hash登记，保持 schema 和当前路由不变，建立 B 对照。
2. 扩内部观察 schema，补正式题型输入、清理前矛盾检查及隐私/坐标契约测试，建立 C 对照。
3. 评测原始多模态输出及自动对应结果，记录部署版本；固定响应单测不能代替真实模型效果评测。源码默认 v7-evidence 不构成准确率结论。
4. 单独实现按需裁图分类与漏检恢复、预算/取消/失败保留及坐标往返测试，测 D/E。
5. 如上述仍无法达到要求，再比较其他文档视觉模型或评估专门训练，另行报告模型切换的收益与成本。

已完成联网资料核对、代码缺口映射及可切换的 v7 代码。后续按用户“识别后自动对应，有错再改”的要求增加自动使用规则；固定响应测试、运行部署和真实模型效果分别验收。已有本地 OCR 单元回归或隔离镜像构建，不属于提示词效果验证。

## 9. v7 源码实施与验证边界

`EDUGRADE_TEMPLATE_ANALYSIS_PROMPT_VARIANT` 由部署环境选择 `v6/v7-text/v7-evidence`，页面资料不能覆盖它。源码默认 v7-evidence；v6 保留兼容及对照，原 system 提示词的 UTF-8 SHA-256 为 `088644693ed68bc951f1dfdee34351a8b55ef73f61cc99341be846873262a5ee`。两组 v7 的正式版本和 hash 使用独立[登记文件](../../ai-services/prompts/template-analysis/manifest.v7.json)，由[登记工具](../../scripts/evals/check_template_analysis_prompt_manifest.py)生成及检查，不修改评分提示词 manifest。

两组 v7 都明确正式填空清单不代表本页存在该题，并补充逐栏检查、无闭合外框填空、完整选择区、混合作答/警示框、静态贴码区与右下留白边界规则。v7-text 保持旧 schema，不要求新字段。v7-evidence 增加 `observed_question_labels`、六项有界 `visual_evidence` 和 `objective_items`；后者包含大区内每题实际题号及带标签的选项坐标，不按顺序猜测。它不增加未校准的置信度字段。

观察交叉校验在角色及题号清理前执行，保留 15/16 误入选择区、身份与选项混淆、警示当条码、静态标签与结构互相矛盾等反证。`instruction` 和 `other` 若有正式题号或作答/身份结构则保留问题框，避免隐藏真实作答区。独立小禁区只有明确警示且没有正向作答结构时转为 `instruction` 并不绘制；混合大框不适用。公开响应移除内部观察，验证通过的 `objective_items` 保留用于自动对应。

`supported` 表示多模态观察、正式题号/题型和几何通过当前自动使用规则，不表示 OCR 独立证实。OCR 未检出不会单独否定有效结果，明确反证仍会降级。前端和 Go 允许支持的自动草稿与教师修正结果直接进入最终模板检查，不要求逐框确认；缺题、重复、冲突及来源修订检查继续保留。

诊断分别记录调用方契约 hash 和最终传输准备模式。兼容路由的 `json_object` 与原生路由的 `schema_in_prompt` 如实记录，不能误称 strict 已生效；发送失败仍可能留有 `transport_prepared`，它不是送达凭证。普通日志不存请求正文、图片、观察原文或凭据。

本轮加入[固定响应回放工具](../../scripts/evals/README.template-analysis-v7.md)。合成矛盾回放只验证分类冲突会被代码保留并降级；它不测真实页召回、模型分类准确率或边界质量。真实 A/B、按需局部复核/漏检恢复、分辨率实验和上线切换仍待分别验收，不能把源码测试数量换算成识别准确率或完成比例。

## 10. 当前页主识别提示词覆盖清单

权威题型来自 `services/api-gateway/internal/paper/validation.go`，与 `apps/web-admin/src/constants/examCatalog.ts` 的 11 项一致；图形/图表、表格/实验属于作答原型，不新增模板角色。以下规则已进入两组 v7 的实际[系统提示词](../../ai-services/grading_agent/template_analysis_prompt.py)，属于输入要求，仍需真实模型评测确认能否遵守。

| 识别内容 | 要求的判断依据与范围 | 输出边界 |
| --- | --- | --- |
| 单选、多选、判断 | 具体题号与重复选项结构；判断可只有 √/×、T/F 等两项，学生孤立答案不能冒充选项阵列 | 外层为完整 `objective_group`；`objective_items` 返回每题及带标签的真实选项框，完整校验后自动对应 |
| 填空、数值、公式 | 实际题号、横线、可填写留白及印刷分界；无四边框也检查，不能把所有横线都当正式填空题 | `answer`；多个题号共用大框却无可靠分界时保留 `uncertain`，不均分 |
| 简答、计算、论述、证明 | 印刷题号、分栏、下一题与完整可用空间；同题小问共用连续空间应覆盖完整题区 | `answer`；不解析答案或评分，不按已写笔迹缩框 |
| 作文、编程 | 方格稿纸、书写横线、代码留白与题区边界 | `answer`；内部小格不作为选择题或身份编号格 |
| 作图、图表与实验 | 明确供考生填写、补图或绘制的坐标图、表格空格等 | `answer`；题干示例图及已有数据表不能仅凭形状成为作答区 |
| 姓名、学号、准考证号、考号、班级、学校 | 本区或紧邻且对应的印刷字段标签，再核对完整填写空间；孤立数字、横线、小格不够 | `identity`；只用既有中文字段枚举，不抄录填写值；`身份信息` 只用于身份用途明确但细分类别不清 |
| 英文身份字段 | Name、Student ID、Candidate No.、Class、School 等真实标签与对应填写区 | 映射既有 `identity_label`；观察中的 `static_label` 不翻译伪造未出现的中文证据，未命中枚举为 null |
| 条码、二维码与空白贴码区 | 对应码图结构或明确贴码说明；空白模板可无实际码图 | `identity`；空框、竖排文字和禁止作答标牌不能证明条码 |
| 禁止作答、注意事项及混合栏 | 独立说明块可界定；正文仅提及姓名、题号不算实际填写字段 | `instruction`；混合栏内的真实作答区要保留，分界不清用 `uncertain` |
| 页眉、页码、分值、缺考标记、定位点、黑边、裁切线、装订线 | 只用于理解版面；不能作为题号或作答区 | 确定无关的独立辅助内容可用 `other`，本操作不生成专属辅助元数据 |
| 子题、同题分离多区与跨页续答 | 只记录本页实际可见具体标签，不展开章节题号范围，不猜上一页归属 | 连续同题空间保留完整框；分离多区/续答保留 `uncertain/unassociated`，不自动合并、排序或补页 |
| 模糊、遮挡、无候选或内容冲突 | 检查整页每栏；候选不是范围限制，证据不足时保留可核对区域 | `uncertain`、null 或未关联；不凭清单补坐标，不用 `instruction/other` 隐藏正向内容 |

网关当前只给整场题号、选择题号和填空题号三组清单，未传每题全部细题型或作答原型；提示词不能声称已获得这些元数据。主识别可直接给出选择题与选项位置，原 OpenCV 网格测量及 Tesseract 数字线索保留为纠错工具；独立页序提示词负责印刷页码与整套排序。主识别不承担内容判分。

v7 的模型自报冲突原因在前端映射成固定中文说明，分别指出题型、身份/选项、条码/禁区、题号及边界问题。未知原因不回显；说明只表示为何需要核对，不表示已经取得独立视觉证据。映射的定向测试不代替实际页面或模型质量验收。

## 11. 真实模型对照的接入缺口

现有教师入口 `POST /api/v1/answer-sheet-templates/{id}/analyze-page` 会核对学校权限、模板修订、来源 hash 和正式题目快照，但只向固定工作节点调用一次，成功后写审计记录。它没有 v6/v7 对照或凭据导出参数，不能把调用此入口描述成完全不写数据库的离线评测。Python 变体由节点环境选择，也不接受页面请求切换。

真实 A/B 需要服务端受控评测桥接：在授权学校作用域中只解析一次当前答题卡模型、冻结同一页字节和正式题目快照，在内存重用凭据，向允许列表内的隔离版本节点分别请求；不启动完整网关副本接入真实队列，不向浏览器或普通日志导出模型凭据。须在调用前后核对快照和学校模型选择，记录每组调用与已知用量，再用人工标注分别评价原始输出和固定后处理。当前仓库尚无这条受控入口，本轮没有创建它或执行真实 A/B。
