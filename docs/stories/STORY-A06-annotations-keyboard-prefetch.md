# STORY-A06：键盘优先、预取与批注

状态：Implemented（当前工作树）

## 范围

- 工作台支持高频键盘操作、下一任务预取、草稿恢复与冲突保护。
- 左侧常驻图标栏直接打勾、打叉、框选和删除标记，不再展开评语编辑器；原切分答题图与评分栏保持可用。
- `review_annotation` 保存任务、页和原图归一化坐标；已有文字批注仍可查看，历史内容不被清空。
- 个人常用评语模板已退役，后端不再提供模板 CRUD 或快捷码使用接口；历史表数据保留，见[移除记录](../api/review-comment-template-retirement.md)。

## 接线

- `internal/reviewannotation` 提供批注的持久化服务、乐观修订和管理端接口。
- 管理端 `ReviewAnnotationWorkspace` 与工作台实际组合。
- 学生可见批注仅使用 `student_after_publish` 可见性，并通过发布成绩范围读取；不复用教师私密 DTO。

## 验证

- 批注存储、学生安全 DTO、阅卷上下文和 Web 类型/构建检查已覆盖关键边界。

## 外部边界

- 键位和预取窗口需要由真实阅卷员长时间使用后调整；不把本机交互测试当作效率基线。
