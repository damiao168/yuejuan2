# Markdown 与数学内容展示

前端只读 Markdown 使用 `apps/web-admin/src/components/MathMarkdown.tsx`。学校 AI 对话的正式回复、流式回复和思考内容，资料核对、题库预览及标准卷说明共用此组件。编辑框继续保存原始 Markdown，不保存渲染后的 HTML。

## 支持范围

- CommonMark 标题、段落、强调、嵌套列表、引用、分割线、换行与行内代码。
- GFM 表格与列对齐、任务列表、删除线、脚注。表格可横向滚动。
- `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 和 `math` 代码围栏中的 TeX 公式，由 KaTeX 渲染。
- 声明语言的代码块高亮、原始代码复制。未知语言保留代码内容。

外部链接显示文字及目标说明，图片显示替代文字；模型提供的 HTML 不执行。学校业务跳转继续由服务端授权的结构化入口提供。脚注允许在当前内容内前往注释、返回引用，不修改应用的 hash 路由。

## 维护边界

`mathMarkdownNormalization.ts` 在解析前兼容旧 TeX 分隔符。代码、链接目标和原文转义受源位置保护，未闭合代码围栏与行内代码的流式中间帧也不先转换成数学内容。

表格分列发生在数学解析之前，因此公式中的竖线需要特殊处理：先在等长解析视图中遮盖，识别表格范围；然后仅暂存表内公式的竖线，在 `rehypeRestoreMathPipes` 中恢复后交给 KaTeX。不得把所有竖线全局改成 `\vert`，这会改变矩阵列定义和其他原文。

聊天及新只读入口设置 `promoteInlineMath={false}`，保留作者的行内/独立公式选择。兼容识别稿的默认长公式提升只作用于普通段落，不能拆开表格、列表、引用、标题和强调。显式独立公式转换后必须让闭合分隔符独占一行，并保留列表或引用的前缀。

共用样式放在 `components/math-markdown.css`，聊天的字号和间距在 `pages/school-ai-chat.css` 覆盖。KaTeX 内部依赖坐标布局，不设置内部强制换行；长公式通过外层横向滚动展示。

## 验证

`MathMarkdown.test.ts` 使用真实 Markdown、GFM、KaTeX 和代码高亮插件做 SSR 回归，覆盖表头/单元公式竖线、容器结构、代码与链接保护、脚注、流式前缀和无效代码语言。修改共享组件还需运行资料核对及对话状态的相关测试，并完成前端类型检查和生产构建。
