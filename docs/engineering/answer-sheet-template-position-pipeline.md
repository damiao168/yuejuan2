# 答题卡模板的定位与区域识别

教师首次上传空白或有字迹的答题卡时建立模板。模板冻结后，学生页面通过配准复用既有题区与选项位置，不再逐张调用多模态判断区域用途。

## 坐标与阶段顺序

1. 检测四周实际印刷定位点；找到完整四点时建立透视基准，稳定范围外遮白。没有完整定位点时保留原图识别，不补造角点。
2. 多模态先看校正副本，报告实际区域用途、静态标签和可见题号。服务将粗框一次逆变换回来源图坐标。
3. OMR、填空横线、身份填写结构及局部模型裁图都使用来源图像素。校正副本的插值可能改变细小填涂格，不反复缩放它来量选项。
4. 局部修复通过内容与合并后的空间检查后原子替换。最后检查覆盖与冲突，输出来源图归一化坐标、定位点及可用的填空共框建议。

运行记录分别保存来源图与首轮校正图的哈希。模型原始响应由受控诊断采集保存；普通报告仅保留类别、原因、几何及调用信息，不转录学生填写内容。

## 实测证据与失败边界

选择题先按实际印刷分隔区测量选项，再用独立静态题号锚点确定对应关系。正式题号清单仅校验题型和范围，不能用于造出漏读题号或均分坐标。连续单选、多选区可在共同印刷边界与实测排布支持时合成整体大框；不同分区独立估计格子尺度，避免涂黑格较大时误删整题。

单题外框包含印刷题号和本题选项，选项小格仍保持独立的实测位置。题号锚点只需足够消歧，不代表每道题的数字都被 OCR 单独读出；未读出的数字可通过本组选项左侧窄带内唯一的黑色字形补全外框。该测量不赋予数字身份，也不移动选项，彩色批注、邻组选项、模糊或冲突墨迹不参与扩框。编辑器不再在选择题小框内叠放蓝色题号标签，原件题号直接可见，系统题号保留在悬停提示和可访问名称中。

已完整通过实测的 OMR 映射，不因末轮模型漏读部分题号而清空。该例外必须绑定当前来源哈希，且现有选项映射仍通过几何和正式题型检查；新增矛盾题号或明确身份、说明等用途反证仍按冲突处理。

填空子题必须实际读到印刷题号，并对应到实测填写横线。整区 OCR 将题号与手写答案粘连时，只补读尚未对应横线左侧的静态窄带，不按缺题清单补题。多题父框只有子题全部恢复后才整体替换，避免静默丢题。共框外沿取实际分隔线，子题仍保留独立 ROI 与成绩，详见 [填空题共区批阅与逐题位置](fill-grading-region-groups.md)。

身份标签和填写结构须共同定位。条码使用可实测的外部实线或虚线框；不存在条码时不报缺失。若身份假框落在唯一实测整题框内，局部修复必须连完整题区一起重读并替换；新响应漏掉原有可靠题目则整批不应用，不能因半截同题重复而无限拒绝修复。

有完整可用证据的结果自动进入编辑器；教师可直接修改实际错误。存在具体矛盾时才保留对应区域和原因，不能以反复模型自证替代实测，也不能把所有识别结果一律交给教师逐框确认。
