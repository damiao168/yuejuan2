# 填空题共区批阅与逐题位置

每道正式题保留自己的 `question_id`、分值和评分细则。教师可以选择同页的多个填空题或该页全部填空题，画一个整区用于共同读图，也可以保留各题独立 ROI 用于逐题查看。整区是批阅配置，不会把已经通过识别的子题改成待核对。

## 冻结配置

`TemplatePage.grading_groups` 独立保存 `{group_id, question_ids, bbox}`。成员至少两题，均须为正式填空题；同一题不能重复、跨组或跨页。外框与页面 ROI 都使用来源页归一化坐标。已有成员子框必须被外框包含，外框不得覆盖身份区、其他题或另一个组。

成员可暂时没有独立 ROI，例如教师已经明确 12、13、14 共用一个作答区，但第 14 题的子框尚未恢复。整区成员映射可满足模板覆盖，不补造第 14 题的精确位置。之后补画子框才能为它提供单题图；切换逐题方式时，缺少子框的成员仍需补齐位置。跨页的全部填空题要按页分别配置整区，不能用一个跨页外框。

历史 `LayoutRegion.grading_group_id` 与 `grading_bbox` 仍兼容，必须成对提供。新旧表示同时存在时，旧字段对应的题目须属于页级组并使用相同外框，不得覆盖页级配置或排除没有子框的成员。

模板内容哈希和准备度快照包含组 ID、成员与几何。内存仓储深拷贝成员切片；模板库保存 `question_nos`，实例化时重映射为新考试的 `question_ids`，不沿用旧考试 ID。切换批阅方式不会改变各题分值、标准答案或评分细则。

## 学生答卷处理

page-processing-worker 使用冻结配置，不再识别学生页面的题号。配准守卫和可见性同时检查逐题框与独立整区。配准完成后，已有单题 ROI 沿用原图；每组另按整区外框裁图并只上传一次。每题仍生成独立 `answer_segment`，共享图片的组成员、外框、像素框、资产 ID 和哈希随各题 `normalized_bbox.grading_group` 保存。

缺少子题 ROI 的成员直接引用这一张共享资产，显式保存 `normalized_bbox.answer_scope=grading_group`。其 bbox 表示真实共享图片的来源范围，不是伪造的单题位置。原逐题识别器与单题图片入口拒绝此类来源；评分启动直接创建逐题人工任务，不用历史单题识别答案自动出分。已有子图的成员保持 `question` 来源（旧记录默认此值）。

提交结果时，网关将这些记录与任务冻结布局核对；共享图必须属于同一考试和当前配准运行或修正预览。各题仍生成自己的 `answer_segment`，修正应用和回滚沿用已有 bbox 快照。

## 阅卷展示

任务 context 的 `answer_artifact` 返回 `answer_scope`，并可附带 `grading_group_id`、`grading_group_question_ids`、`grading_group_image_url` 和 `grading_group_tasks`。共享 URL 复用已授权的 `segment-image?scope=grading_group`，读取时再次核对资产所属运行、考试与哈希。仅有整区来源时 `segment_image_url` 为空；已有精确 ROI 的成员仍可查看单题图。

配置共区的任务首次默认展示整区；有单题图时提供“整区 / 单题”切换。数学步骤框与题区批注依赖子题坐标，不能叠到共享图上；缺子 ROI 时不提供这些单题工具。

整区工作台同时展示例如 12、13、14 的独立录分行，每题使用自己的分值、量规、草稿版本和任务版本。可聚合的任务必须是同份答卷、同页、同配准与评分运行、同评分轮次、同共享图片资产，且已分配给当前阅卷人；未分配给本人的题目需先完成分配，不因图片相同而取得其他题目权限。

每行显式保存草稿和提交成绩；整区模式暂停原当前题自动保存，避免同时修改同一草稿版本。提交一行成功后保留其他行的输入，不跳走或重新读取并覆盖未保存内容。一行失败只在该行显示状态并保留输入。后端复用原逐题提交事务与幂等回执，不承诺多题原子提交，也没有新增整组领取接口。
