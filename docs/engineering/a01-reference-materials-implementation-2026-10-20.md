# A01 参考图片参与试改：实施与验收记录

日期：2026-10-20。状态：核心实现与合成验收完成，未生产启用。对应 [详细设计](../architecture/a01-reference-materials-design-2026-10-19.md)。本次保留原工作区未提交内容，不提交、不部署、不修改现用业务数据库。

## 实际行为

- 原题目评分配置增加参考图抽屉，复用导入图片、已登记 PDF 页图、已物化题库图片。只使用当前有效导入代次的未删除来源。
- 支持鼠标拖框、整数像素调整、服务端 PNG 裁图和真实输出核对。来源图加载完成后才可裁图，实际裁图显示后才可确认加入；JPEG 的 8 种 EXIF 方向统一到与预览相同的坐标空间。
- 题目图、参考解答图各最多 2 张，总计最多 4 张；显示、保存和实际请求均按题目图→参考解答图→学生作答排序。每题显式选择 `text_only` 或 `reference_images`；历史缺省保持 `legacy_unrecorded`。
- 保存清单、原命令收据在同一事务完成。清单及图片项只在创建事务写入，提交后不可追加或替换。确认准备和开考按固定顺序锁清单、锁文件，再核对可用状态。
- 冻结参考绑定与准确评估快照 ID/哈希一起进入准备伴随快照；教师任务及试改读取该绑定。材料撤回、资产隔离会阻断后续调用和未结算建议，历史内容及发送事实保留。
- 数学 v2 单模型请求实际携带参考 PNG 数组、独立角色、清单及请求绑定摘要。参考图片、图中文字不能充当学生得分证据；评分仍由原服务器证据与采分点流程结算。
- 入队前检查当前实例多图能力和准确部署的 image 审批，实际消费许可时再次检查。没有批准的部署不会自动替换成其他模型，也不会把必需参考图静默丢弃。
- PostgreSQL 持久化一次性执行许可、线上请求摘要、尝试/响应/未知阶段与已报告用量；逐样本展示发送事实。已消费许可不能因重启、HTTP 超时或租约接管重新发放。

## 命令恢复与权限

浏览器只在当前租户、操作者、考试和题目范围下保存不透明命令 ID，不持久化教师输入或图片。查询原结果使用只读 GET。显式 POST `.../questions/{questionId}/reference-material-commands/{commandId}/resume` 有两种结果：

1. 已登记裁图但对象未完成：从服务器原元数据恢复相同裁图，沿原资产 ID 上传并激活。
2. 没有业务回执：取得与原写请求相同的命令锁，写入封闭记录；迟到原请求不能提交。客户端再读当前材料后才允许重新编辑。

会话、账号或题目切换后，旧异步结果不能修改新上下文；Blob URL 在替换/卸载时释放。恢复成功也重读当前冻结/撤回状态，不将旧成功回执当成当前材料状态。

来源、原页和派生图均受同租户外键、RLS、文件生命周期及对象键引用保护。通用文件下载拒绝 `question_reference_crop`；材料图经精确考试/题目或任务范围入口读取。使用许可的 HMAC 凭据只授权准确租户/run/permit 回调，不授予通用 worker 能力，不进入模型消息。

## 配置和启用前提

新增迁移为 `000198_question_reference_materials.sql`、`000199_subjective_reference_dispatch.sql`；示例和 compose 的 schema 元数据已由官方脚本同步至 `000199`。本次仅在临时数据库运行这些迁移。

部署管理员启用前需要同时满足：

- 现有数学 v2 开关和 `local_llama_cpp` 评分适配器可用；Agent 与 Gateway 使用匹配的配置及服务凭据。
- Agent 配置 `EDUGRADE_GRADING_MATERIAL_CALLBACK_BASE_URL` 指向内部 Gateway；示例默认留空，不自动启用。HTTPS 及服务地址校验沿原服务规则。
- 当前已认证实例 `/grading/capabilities` 报告 `material-input-v1`、上限 4、实际 adapter/provider/deployment/region 与当前 wrapper 摘要。
- 准确部署的 `CapabilityPolicy.math_wrapper_hash` 与该摘要相同，并存在匹配 model、prompt、rubric、学科、年级、题型和 image 模态的有效审批。
- 学校的图像外发、预算和现有数学证据/租约/人工复核门禁通过。

`/ready` 或文字调用批准均不能证明多图可用。预检只反映当次读取的配置；外部治理策略没有跨系统事务锁，不承诺与已在途请求瞬时原子撤销。

## 有意收紧与验证边界

带参考图的扩展目前每个 permit **仅一次供应商调用，不自动 schema repair**。这是比设计备选上限更窄的实现；旧路径保留原规则。`dashscope_native` 与 Panel 带图请求明确阻断。

许可消费后若进程中断，即使没有可靠传输回执也保留“可能已发起”。普通成功路径沿原 run/grade 持久化；本次没有增加供应商原始响应归档或一键重新调用。无法只读恢复结果时保留未知，教师继续人工阅卷，不能自动重发。
