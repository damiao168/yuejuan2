核对日期：2026-10-19。状态：设计提案，未实施本项业务代码，未用真实学生答卷或真实模型证明效果。本文只记录实际审读范围，不是全仓审读。源码位置为本次工作区观察值，后续实现应以函数名重新定位。
整合结论以 [详细主方案](../../architecture/a01-reference-materials-design-2026-10-19.md) 为准：一期全部选中图必需，optional 是后续备选；已物化的有效 PDF 页图可选；许可已消费但缺可靠传输记录时显示“可能已发起，待核实”，不能因缺 attempted 记录显示未发起。

## 2. 首期教师操作

1. 教师在原“添加试卷资料”上传资料，完成当前已有的识别与题目结构核对。
2. 在“小题与分值 → 第 N 题 → 题目与答案”看到“本题参考图”。无图时显示“未配置参考图；仅文字题可继续按文字依据处理”。不能从题型或 OCR 猜测已经完整。
3. 点“从已添加资料选图”，抽屉顶部固定显示考试名、题号；来源仅列当前考试中教师有权使用的文件。默认定位本题 `source_refs`，但教师仍需确认。
4. 选择来源后显示整页和当前页码；框选图与其必要条件、图例、文字标注。点击“预览选区”显示实际拟保存图片，防止只看细框却漏掉辅助线或字母。
5. 为每张图选择“题目图”或“参考解答图”，填写简短说明（例如“几何条件图”“作辅助线后的解答图”），指定是否为 AI 评分必需；确认本题归属后保存。
6. 回到题目页，以有序行展示缩略图、说明、角色、必需状态、来源及页码。允许“查看原图”“调整选区”“替换来源”“移除本题关联”，支持按钮上移/下移，不要求拖拽。
7. 点原“保存题目与答案 / 保存本题全部修改”时保存材料修订；服务端返回并回读同一版材料后，才显示“已保存”。新题未获服务端 ID 前只保留草稿，不能提前成为可发送材料。
8. 原“确认准备完成”复核页补“逐题参考图”：第 N 题、题目图 1、解答图 1、必需 2、材料已核验。可只读预览，也可返回本题修改；不能直接在冻结弹窗中替图。
9. 冻结后相同清单在人工阅卷与 A02 试改中只读。A02 提交前检查冻结材料可用，随后按原流程先保存 5–10 份独立人工基准，再发起试改。
10. 每份 AI 建议下可展开“本次使用的参考图”，核对其角色、顺序、版本与发送状态；同题扩批沿用该试改绑定材料，再由服务端检查是否仍可发送。

首期裁切源以方案统一确定的 PNG/JPEG 图片页为准。已有 PDF 导入继续存在；只有服务端已生成可校验的页图时，PDF 来源才能开放选页裁切。浏览器 PDF canvas 只用于预览，不能上传任意 canvas 后冒充原文件的权威裁图。若本期不实现服务端 PDF 页图，明确提示“此 PDF 尚无可选页图，请先通过现有资料入口补充对应图片”，不能承诺原生 PDF 已参与模型调用。

## 3. 材料字段与默认行为

| 教师概念 | 界面要求 | 业务边界 |
| --- | --- | --- |
| 所属题目 | 抽屉和每次保存均展示“本场考试 · 第 N 题” | 题目归属由服务端验证，不能只依赖当前页面选择 |
| 图片角色 | 仅“题目图 / 参考解答图”，分别显示 | 与整份资料类型、学生作答图、A02 样本类型是四种不同概念 |
| 必需 | 默认选中“AI 评分需要此图”；取消时解释“无此图也可按其余材料处理” | 必需图不可用时阻断相关 AI；可选图不可用也要留排除原因，禁止静默漏图 |
| 来源 | 文件名、页码、题库来源或资料来源 | 不接受外链 URL、学生身份页或无本考试授权的文件 |
| 范围 | 预览选区；坐标可精调 | 固定规范坐标与旋转语义，后端检查越界、零面积；不要把 CSS 像素作为保存坐标 |
| 说明 | 便于区分的短标签，作为图片替代文本基础 | 说明不能替代图片内容，也不是隐式评分规则或系统指令 |
| 顺序 | 题目图在前、解答图在后；同角色内显式顺序 | 请求顺序和回执顺序一致，排序改变必须产生新修订 |
| 保存状态 | 未保存、保存中、已保存、结果待核实、版本冲突 | 选区预览成功不等于保存成功，更不等于已冻结或已发送 |

“必需”是本地业务提案，不是从竞品已验证的默认值。正式上限（张数、单图字节、像素、总请求预算）由权威服务端契约提供，前端显示同一来源；不得在两端各写不同上限或把模型厂商上限直接变成产品承诺。

## 4. 冻结、试改与发送回执

- 材料保存修订进入题目与考试配置摘要；旧冻结核对弹窗不能确认新图，重新读取后才允许再次核对。新增、移除、裁切、角色、必需与顺序改变都视为材料修订。
- 准备冻结已完成时只读；当前活跃考试不提供“热替换”。如确需新依据，走项目正式的版本/重新冻结流程；首期不额外发明解冻快捷入口。
- `FrozenReferenceImages`（拟新增）只消费服务端冻结材料 read projection，供 `FrozenQuestionReference` 与 `TrialScoringDrawer` 共用。人工任务用任务绑定快照，试改历史用试改绑定快照；不能将当前题库材料拼到历史报告里。
- A02 新建前展示“参考图：2 / 2 可用，必需图 2 / 2”；缺必需图、未授权、哈希不符、损坏、超限或模型准入失败时禁用“保存人工基准并试改”，保留人工分草稿并给出可执行原因。服务端必须再次校验，按钮禁用不是授权边界。
- 可选图排除时展示具体行及原因，教师能预览最终拟发送清单；不自动把它降为必需，也不以“材料完整”总标签掩盖缺项。
- 分清“冻结材料清单”和“本次发送记录”。前者证明本次依据绑定了哪些图；后者只来自实际模型请求尝试，不从清单、队列任务成功或返回分数倒推。
- 每次尝试显示模型请求时间、请求/尝试标识、材料清单版本、图片角色/顺序/短摘要、发送状态与原因。哈希等技术信息默认折叠在“核对详情”，教师主流程显示可读名称和版本。
- 状态至少区分“尚未调用”“校验阻断，未发出”“发送结果待核实”“已发出请求”“无历史发送记录”。只有客户端确实获得的传输事实才使用相应文案；HTTP 响应并不证明模型理解图意。
- 调用超时且无法确认请求是否发出时显示未知；重试沿用系统原任务/幂等规则，单列每次尝试，不能把前次标成“未发送”或重复计为新批次。
- 历史没有回执时显示“本次参考图发送情况未知”，保留原评分依据；不能伪造零图、从新题库补图，也不能把未知误认为模型未看图。
- 旧材料下试改的扩批决定不能放行新材料；依赖变化、撤权或图片不可用后显示“本次试改依据已不可用，请停止扩批并人工核对”，迟到结果不能覆盖当前依据。
- 更新参考图不重置 A02 独立性：已创建 AI 运行或已有同版 AI 成绩的作答不可当新独立人工基准。已取消且从未创建运行/开始 AI 的批次可由服务端重新判定；不能由前端 `state === review` 自行认定可用。不足 5 份时转人工，首期不复用污染后的原样本。
- 保留既有 `trial_sample` 强制人工复核、同题扩批、决定理由、revision 并发检查与正式成绩隔离；A01 不新增自动发布成绩。

## 5. 组件与状态建议

| 位置/拟新增单元 | 职责 | 不应承担 |
| --- | --- | --- |
| `PaperQuestionForm` 内 `QuestionReferenceMaterialsPanel` | 本题材料行列表、保存状态、编辑入口、只读呈现 | 新文件上传、学生作答裁图、评分细则编辑 |
| `ReferenceMaterialPicker` | 当前考试授权来源与页、单图选区、角色/必需/说明、拟保存图预览 | 从浏览器提交文件授权事实或任意外部 URL |
| `useReferenceMaterialDraft` | 草稿/服务端修订比较、owner、原命令恢复、版本冲突 | 以本地存储批准 AI 或抹除远端已保存事实 |
| 中性 `useProtectedPagePreview` | 复用 PDF/图片读取和清理边界，提供稳定页面尺寸与预览 | 复用答题卡的限制文案、把浏览器像素输出当权威摘要 |
| `PreparationFreezeModal` 材料列/详情 | 逐题材料总览与冻结摘要复核 | 在确认窗口直接修改材料 |
| `FrozenReferenceImages` | 同一冻结材料 projection 的有序缩略图、受保护预览、不可用状态 | 查询可变题库或暴露 storage URL |
| `AIReferenceInputReceipt` | 本次请求尝试的实际图像发送事实 | 显示“模型已理解”“准确率已提高” |
| `useScoringTrials` 扩展 | 同步读取试改绑定材料与准入结果，恢复原命令 | 覆盖已保存人工基准、绕过服务端 covered 判定 |

材料草稿 owner 至少绑定 tenant、school/authorization scope、teacher、exam、question、business session generation、permission 与源文件/材料修订。任何变化先清旧预览引用、取消读取、关闭旧选择器、撤销 Blob URL；旧 Promise 成功/失败/finally 均不能改新 owner 状态或继续发写请求。资源清理迟到不能清掉新文档，沿用既有 `useTemplatePreview` 的解绑后清理顺序。

保存响应丢失后保留原 command 与 payload，不允许边改材料边以同一 command 重试；优先查原操作结果。明确 400/422 拒绝可恢复编辑；409 读最新版本后比较，不自动覆盖他人修改；未知网络结果只读回执/重试原命令。远端保存成功而列表回读失败显示“已保存，等待状态刷新”，只重读，不能重复生成裁图或把成功记录删掉。

## 6. 窄屏、键盘与文案

- 桌面沿用原题目详情，选择抽屉用左右“来源页 / 当前选区”布局；小于 768 px 改上下分步“选来源 → 调整范围 → 核对归属”，不出现套娃横向滚动。
- 320 px 和 200% 缩放时，主要按钮换行、文件名可折行，角色/必需字段有文本 label；操作栏不能遮住选区、错误或最后一行材料。
- 不能只有鼠标框选：提供“使用整张图片”、四项范围数值和页面选择，可用 Tab 完成；聚焦选区后方向键微调、Shift 加大步长，Esc 退出调整且保留已保存材料。
- 所有编辑入口、角色、必需、范围、保存、只读预览有可访问名称；状态用 `role=status`，阻断原因用 `role=alert`；关闭选择器后焦点回到原“选图/调整”按钮。
- 保存中防双击但不锁死查看来源；冻结后移除写入口，保留预览、来源说明与回执查看。预览出错不要把整页内容清空。

| 情况 | 建议文案 | 可执行动作 |
| --- | --- | --- |
| 材料未保存 | 本题参考图有未保存修改，保存后才能核对冻结依据 | 保存本题 / 放弃本次修改 |
| 选区过小/漏图提示 | 请保留图形、图例和必要条件；预览中应能看清字母与辅助线 | 调整范围 / 查看原图 |
| 必需图缺失 | 本题缺少必需参考图，暂不能使用 AI 建议；人工阅卷可继续 | 查看缺失项 / 返回本题资料 |
| 只读 | 本场参考图已随准备冻结，此处仅供核对 | 查看冻结原图 |
| 保存未知 | 本次保存结果尚未确认，请核对原操作；当前内容已保留 | 重新读取原操作 |
| 已保存回读失败 | 参考图已保存，页面状态尚未刷新，无需再次保存 | 重新读取保存结果 |
| 版本冲突 | 本题材料已被更新，请读取最新版本后重新核对 | 读取最新版本，保留本地草稿供比较 |
| 发送未知 | 本次请求的参考图发送结果待核实，不能据此判断模型已收到 | 查看本次请求记录 |
| 已发出 | 已在本次请求中发送 2 张参考图；仍需核对 AI 建议与证据 | 查看实际发送清单 |
| 依赖失效 | 参考依据已变化或不可用，原试改不能继续扩批 | 查看原依据 / 继续人工复核 |
| 独立样本不足 | 剩余未接触 AI 的同题作答不足 5 份，请继续人工复核 | 返回人工阅卷 |

## 7. 可验证验收矩阵

以下是开发验收条件，本次设计阶段未执行这些测试。至少分 API/数据库、Go→Python 请求结构、React 状态与浏览器合成流程四层提供证据，不能只凭页面截图认定已接入模型。

| 编号 | 输入与触发 | 必须观察到的结果 |
| --- | --- | --- |
| UX01 | 从现有 PNG/JPEG 资料选题图与解答图，各裁一张 | 题号、角色、必需、顺序、源摘要与派生图摘要保存后回读一致；不出现新一级导航或第二套上传 |
| UX02 | 仅打开来源/仅画框后关闭 | 不产生可发送材料；回到本题保留已保存列表 |
| UX03 | PDF 尚无服务端可校验页图 | 原资料预览仍可用；裁切入口明确不可用，不把 canvas 或 PDF 外链直接交模型 |
| UX04 | 旋转页、越界框、零面积、超数量/字节/像素 | 前端可说明，后端独立拒绝；坐标与预览一致，旧成功材料保留 |
| UX05 | 保存响应丢失后刷新或重开 | 同一 owner 恢复原 command；查询/重试不重复建图，不可换 payload 冒用同命令 |
| UX06 | 保存成功但回读失败或本地清理失败 | 显示已保存待刷新；只重读；不把成功材料清空 |
| UX07 | 两教师并发修改、旧 revision 保存 | 后者收到冲突并保留草稿；不覆盖已提交新版本 |
| UX08 | 打开冻结复核后另一窗口替图/改角色/必需/顺序 | 配置摘要变更，旧确认被服务端拒绝；重新复核显示最新材料 |
| UX09 | 已冻结考试进入题目页及人工阅卷 | 题图只读且来源于绑定快照；更改题库原材料不能热替该考试内容 |
| UX10 | A02 新建前缺必需图/权限撤回/损坏/模型不支持 | 该题 AI 被阻断并给出原因；人工阅卷可继续；直接 API 亦不可绕过 |
| UX11 | 可选图不可用 | 排除原因与最终清单明确；回执不能宣称该图已发送 |
| UX12 | 正常样本试改 | 5–10 份人工基准先保存；请求载荷确含冻结题图和解答图；样本显示准确 attempt 的材料回执 |
| UX13 | 只建任务、排队未调用 | 显示尚未调用；不能根据任务 ID 或清单把状态写成已发送 |
| UX14 | 请求超时/回执丢失/历史无回执 | 分别显示待核实或无历史记录；不伪造未发送、已理解或零费用 |
| UX15 | 看旧试改报告，此时有更新题库材料 | 查看原试改绑定图片；扩批由原 fingerprint 与当前授权共同校验，禁止拼当前图 |
| UX16 | 材料变化/撤权后旧扩批或迟到模型返回 | 旧决定不能放行新依据，迟到结果不能覆盖当前试改状态；原报告仍可审计 |
| UX17 | 停止已开始 AI 的试改后补图重新选同份作答 | 服务端 covered 拒绝独立样本；无运行的取消批次由服务端区别处理；不足 5 份只能人工 |
| UX18 | tenant/school/teacher/exam/question/session/permission 分别切换，旧读写/预览 Promise 随后返回 | 旧数据、错误、busy 与图片不进入新页面；旧回调不发新写请求；服务端拒绝越权 ID |
| UX19 | 使用学生身份页、无权题库附件、任意外链 URL 替换材料 | 服务端拒绝；日志不泄露原文件地址或其他学生身份 |
| UX20 | 320 px、768 px、200% 缩放、仅键盘完成来源选择与保存 | 内容可读，无不可达主按钮；键盘可精调；关闭恢复焦点；错误可感知 |
| UX21 | 在 FrozenReference 与 TrialDrawer 看同一冻结题 | 共用组件显示相同角色/顺序/版本；图片通过受保护读取，无永久公开 URL |
| UX22 | 全流程后检查正式成绩与发布状态 | 仍只有 AI 建议；试改样本强制人工复核；A01 不自动改正式分、不自动发布 |
