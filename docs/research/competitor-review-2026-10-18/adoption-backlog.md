# 竞品经验吸收任务清单

研究日期：2026-10-18（Asia/Shanghai）。本文将本目录已记录的竞品经验转成 **20 个候选产品任务**，用于后续评审和取舍；本轮只研究，没有修改业务代码、运行模型评测或承诺真实节时、准确率与教学效果。竞品功能的证据强弱以各分组报告为准，公开帮助文档、厂商截图、历史案例、第三方文章和真实登录操作不能混算。

本地对照编号统一引用 [local-baseline.md](local-baseline.md)。本轮又定向读取了当前工作树的关键实现，目的在于避免重复立项，不构成全仓审读、完整功能验收或安全评审。未读到的实现继续为 `pending`；下文的“增量”是候选范围，进入开发前仍须核对相关接口、数据模型和当前变更。

## 立项口径与优先次序

- **P1**：优先验证评分事实、证据完整性和阅卷运营的真实痛点；不是故障等级。
- **P2**：增强交付、教学闭环和易用性，在有学校使用场景后实施。
- **P3**：依赖明确客户需求、外部平台或额外研究，先做可行性验证。
- **S / M / L / XL**：分别表示单模块呈现、数个模块协作、跨前后端的数据与流程、跨契约及历史数据迁移的相对规模。不是工期、人数或交付日期。

## A01 — 题目图、参考解答图、评分样例图作为可追溯评分材料

- **触发场景：** 图形证明、实验图、地图或化学结构题无法只靠参考答案文字核对；教师在图片中写出关键方法。
- **竞品证据：** [#31 小作坊](https://jxxzf.cn/) 描述题目/答案/要求/示例四页、参考图和截图；[#14 Knowable](https://www.knowableeducation.com/) 将题目卷、评分细则和学生作业分开；详见 [22–31](products-22-31.md) 与 [11–21](products-11-21.md)，均未验证模型真实评分效果。
- **本地已有 / 对应编号：** L07、L11–L13、L20、L28 已有学生题块图、数学证据、评分示例与图文外发治理；当前资料导入类型也已有 `source_refs`，不能说本地完全没有参考来源。定向读取未确认“参考图→冻结→模型消费→教师证据”整条链已完整打通。
- **真正增量：** 材料按题目图、参考解答图、评分样例图区分角色；每项记录来源、哈希、版本、适用题目、可见范围和是否实际进入本次模型请求。教师可并排查看学生作答与对照图。
- **实现边界 / 依赖：** 先设计冻结材料清单和图片授权契约；复用允许部署、图片外发开关和模型能力证据。不能将整页含身份信息的图片直接作为通用外发附件，也不能把学生答图冒充参考图。缺图、无权限或模型不支持时明确转人工，已冻结考试不静默换图。
- **有意义验收：** 用带参考图的几何题、缺图题和被替换材料各回放一次：本次请求与教师视图引用同一版本；缺图可人工继续但不能显示“已参考”；授权被撤回后不能读取旧地址；旧建议因依赖材料变化而失效。真实学科效果另用授权样本验收。
- **优先级 / 规模：** P1 / L；依赖冻结材料与模型请求契约，不能只加上传按钮。

## A02 — 少量试改、差异核对、成本预览后再扩批

- **落地进度（2026-10-19）：** 首期试改与决策闭环已实现并通过前端、后端、真实 PostgreSQL 和合成浏览器验证。人工基准先于 AI，按当前答案版本排除已有 AI 运行或成绩的样本；同题扩批剩余答卷最多 1000 份。服务端保存基准、批次、理由和版本依赖；停止及失效后拒绝迟到结果。预计费用区间、剩余额度及真实模型效果尚未验收，不能把整项成本预览计为已完成。见 [验证记录](../../../reports/scoring-trial-2026-10-19/verification.md)。
- **触发场景：** 新题型、新规则或新模型第一次进入某场考试，负责人希望先发现明显偏差，再决定是否扩大 AI 建议生成范围。
- **竞品证据：** [#3 AI 批改助手](https://aimarking.five-plus-one.com/) 的试改模式；[#28 阅卷易](https://yuejuanyi.cn/) 建议先单次试判；[#25 GradeSense](https://gradesense.in/pricing) 公开按页额度；[#31 小作坊](https://jxxzf.cn/) 展示 Token/耗时。见 [1–10](products-01-10.md)、[22–31](products-22-31.md)。
- **本地已有 / 对应编号：** L15、L19、L28；当前已有评分启动条件、题级 run 进度、AI 重试，模型治理已有授权冻结评测集、成本/延迟指标、每题/整考成本上限及影子比较。增量不是重做评测或预算策略。
- **真正增量：** 在本场考试中选择可追溯试改样本，展示人工对照、严重差异、证据缺失、实测耗时和用量；按页/题/模型调用清楚区分计量单位，显示扩批范围、预计区间、剩余额度和估算依据。负责人作出可审计的扩批决定。
- **实现边界 / 依赖：** 试改不改正式成绩；样本不足、供应商未回用量时显示未知，不能按零成本或高置信度放行。AI 独立多评、同模型重复采样或第三模型仲裁都不等于两名教师独立双评，不能占用或替代本地教师双评事实。沿用预算限额和供应商准入；任何扩批只扩大建议生成，不放宽 AI_FAST_CONFIRM 的教师看图勾选、R1/R2、非数学、无评分点、无风险、至少 0.95 等条件，不自动终审或发布。
- **有意义验收：** 样本中故意放入证据不完整与高风险题，报告能展示差异且不会纳入快捷确认；改变规则后旧试改结论不能复用；超预算、取消、重复点击及未知用量都有确定结果，恢复时不产生重复批次。费用预估与实际用量分别保留，不宣称必然节省。
- **优先级 / 规模：** P1 / L；先复用现有 run、评测与预算服务，再补面向考试负责人的决策入口。

## A03 — 纠错只改当前答卷，规则改进另成草稿

- **触发场景：** 教师反复纠正同一种等价答案、方法分或扣分条件，希望改进后续规则，又不想让单个特殊答案影响整场考试。
- **竞品证据：** [#3 AI 批改助手](https://aimarking.five-plus-one.com/) 区分“仅修改分数”和“下一步分析”；[#25 GradeSense](https://gradesense.in/features) 宣传评分记忆及 Improve AI；主 agent 复查 [#21 迈阿密大学 Gradescope 支持页](https://lpt.it.miami.edu/platforms/supported/gradescope/index.html) 与 [官方上手页](https://www.gradescope.com/get_started) 读到边评分边建立/修改 Rubric、点值调整和个别学生调整的公开说明。见 [1–10](products-01-10.md)、[22–31](products-22-31.md) 与更新后的 [11–21](products-11-21.md)。
- **本地已有 / 对应编号：** L10、L13、L18–L20、L28 已有教师改分、冻结 Rubric、数学版本绑定和模型评测；`reviewContext.ts` 明确不以最新可编辑题库替代任务快照。
- **真正增量：** 将经授权的分歧案例整理为新答案/Rubric 版本草稿，展示规则差异、正反样例、适用学科/题型/题目、拟影响范围、回放结果、审批与撤回记录。
- **实现边界 / 依赖：** 普通教师纠错不能直接改全局规则或运行提示词；草稿默认只供讨论。已冻结考试继续使用原快照；确需正式重评，必须走独立授权、版本化重评和重新发布流程，保留原成绩与申诉关联。模型/提示词修改另走既有治理流程。
- **有意义验收：** 一条只适用于个案的修正不会改其他答卷；两个版本并行时可查清每份建议的依据；新草稿在正例改善、反例退化时都如实显示；未审批或回放失效时不能启用；撤回不删除历史证据。
- **优先级 / 规模：** P1 / L；依赖授权样本和回放能力，不能以“模型记住了”作为验收。

## A04 — 原卷局部、识别片段、规则与分数双向联动

- **触发场景：** 教师看到“少 2 分”但找不到原卷对应内容；历史、语文或实验题的证据散在图像、文字和评分面板中。
- **竞品证据：** [#11 Kinkao](https://www.kinkao.cn/product/39.html) 将拖拽扣分落在答案位置；[#26 Grade AI](https://www.gradeai.us/demo) 展示原答卷、OCR、命名扣分规则和草稿分；[#15/16 GradeLab](https://gradelab.io/ai-grading) 的关键短语高亮。见 [11–21](products-11-21.md)、[22–31](products-22-31.md)。15/16 同址只计一份证据。
- **本地已有 / 对应编号：** L08、L11–L13 已有可关联评分点的批注，数学步骤已支持 `step.bbox`、由 block 框回退计算、版本绑定和点击定位，不能将数学联动重复立项。
- **真正增量：** 复用数学事实绑定经验建立跨学科证据锚点；从规则/扣分理由跳到原图局部与文本，从批注反查对应评分点。可逐条标记支持、不支持、待核对，并保留教师覆盖理由。
- **实现边界 / 依赖：** 坐标必须说明页面、题块坐标系和证据版本；无可信坐标时显示“无法定位”，不能生成看似精确的框。联动只是依据展示，不暴露模型隐藏思维链，不因拖拽批注自动修改已提交成绩。
- **有意义验收：** 在跨段引用、两条规则共用一处证据、OCR 与图像不一致三种样例中，定位与反查均能解释；旋转、切题、证据更新后旧高亮不能串到新图；没有原图权限的用户无法通过锚点绕过权限。
- **优先级 / 规模：** P1 / L；先支持现有证据类型，新的音视频/代码证据另做契约验证。

## A05 — 一题跨页、同页多块的有序作答区域

- **触发场景：** 学生解答写到下一页或续答区，同一题有图表、文字、补写等多块，单个 ROI 容易遗漏方法分。
- **竞品证据：** [#20 Crowdmark 灵活阅卷](https://crowdmark.com/new-feature-flexible-grading) 明确同页多题与跨页一题，属于 2017 历史公告；[#17 MyLesson](https://www.mylesson.ai/ai-grading) 声明多页合并。见 [11–21](products-11-21.md)。
- **本地已有 / 对应编号：** L21 已有多页来源和页序；当前 `regionLifecycle.ts` 明确正式协议是一题一个 ROI，额外区域保留为 `MULTIPLE_REGIONS_UNSUPPORTED` 待核对候选，不能当成自动跨页评分已支持。
- **真正增量：** 一个题目绑定有序区域列表，每块有页号、区域 ID、来源版本、坐标及阅读顺序；教师可看整组与单块，AI 证据能说明引用哪块。题级任务仍是一份完整评分事实。
- **实现边界 / 依赖：** 同步扩展模板、锁定检查、切分结果、任务上下文、AI 输入、批注/申诉坐标和导出；只拼大图不能代替身份/页序核验。历史单 ROI 无损兼容，缺页、重复页、错学生和区域变化不得静默进入评分。
- **有意义验收：** 用同页分离区、跨两页、缺续页、错页序及单 ROI 历史数据回放；人工与模型看见同一有序材料；缺块阻断完整性确认；更新其中一块使旧建议失效；双评两人得到相同冻结区域集合。
- **优先级 / 规模：** P1 / XL；先做契约与迁移方案，再改画布。

## A06 — 可解释的多等级、多维度评分量表

- **触发场景：** 作文、项目或开放题需要按论点、证据、组织等维度选择表现等级，单个“给几分”难以保持一致。
- **竞品证据：** [#17 MyLesson Rubric Generator](https://www.mylesson.ai/ai-rubric-generator) 的 analytic/holistic/single-point、逐格描述；[#24 ExamSoft](https://support.examsoft.com/hc/en-us/articles/11166571442829-Legacy-Portal-Grade-Essay-Questions) 的多 Rubric/权重/行级评论；[#5 百問繚乱教师记录](https://note.com/umeducation_jp/n/n274bdb4ec849) 的课程评价维度汇总。见 [11–21](products-11-21.md)、[5/6/8](products-05-06-08.md)。
- **本地已有 / 对应编号：** L09、L20、L22 已有采分点、结构化扣分、评分示例、合计校验和知识点报表；学科工具提示含 Trait 评分字样，不能仅凭提示认定等级量表全链完成或完全缺失。
- **真正增量：** 增加量表类型、维度、等级描述与分值/权重预览；可按维度写反馈，报告按自定义评价轴汇总，区分知识点与课程能力维度。共享模板可预览后采用。
- **实现边界 / 依赖：** 先确认单点量表如何形成分数或仅形成达成描述；清楚解释加分/扣分、权重、取整和总分覆盖规则。不得将日本课程类别直接套为国内标准，也不放宽现有满分与说明要求。采用后冻结版本。
- **有意义验收：** 同一作文在等级选择、权重组合、零分/缺评、手工总分调整时合计可复算；等级描述、行级评语与已发布反馈对应同一版本；维度报告展示样本量，未评分不会被统计成零分。
- **优先级 / 规模：** P2 / L；先选一种真实开放题试点，避免一次支持所有量表。

## A07 — 作答模板、内部评分说明和发布反馈分开配置

- **触发场景：** 同一份材料既有学生作答脚手架，也有教师参考答案，错误可见范围可能泄题或泄露内部备注。
- **竞品证据：** [#23 Moodle Essay](https://docs.moodle.org/en/Essay_question_type) 分开 Response template、Grader information 与 General Feedback，并配置文件类型和字数；文档中的 Require text 不强制阻止提交，不能当作可靠必填校验。见 [22–31](products-22-31.md)。字体/间距、隐藏题干和打印等阅读控件的本轮证据属于 #24 ExamSoft，本文不归于 Moodle。
- **本地已有 / 对应编号：** L10、L20、L24 已区分 AI 学生反馈、教师内部备注、冻结评分材料和发布版本。
- **真正增量：** 材料字段显式声明“给谁看、在何时看”：作答前、提交后、成绩发布后、仅评分人；提供教师/学生预览和缺项提示。文件题再补支持类型、附件是否必交、字数适用范围的配置说明；这是本地待评审设计，不把 Moodle 的提示型设置当成已验证的强制提交门禁。
- **实现边界 / 依赖：** 可见范围由服务端投影，不靠前端折叠保密；冻结材料和发布版本保存当时受众规则。提示、阻断与人工例外要分开定义，若本地确需强制必交须由服务端明确验证。字数规则不能直接套到手写 OCR，不因 OCR 漏字自动扣分。

## A17 — 学生失分到针对性补练、订正和再测

- **触发场景：** 学生已经能看失分题和教师反馈，但完成下一步练习后没有地方记录是否掌握。
- **竞品证据：** [#2 七天网络](https://www.7net.cc/build/product/sjchanpin/index.html) 的高频错题滚动练/个性方案；[#9 慧阅卷](https://cms.17yuejuan.cn/) 的错题订正状态；[#1 Gradyn](https://www.gradyn.ai/) 的同失分点练习；[#31 小作坊](https://jxxzf.cn/) 区分考试分数、作业达成度与个性补练。见 [1–10](products-01-10.md)、[22–31](products-22-31.md)。
- **本地已有 / 对应编号：** L22、L24 已有逐题反馈、只看失分题、圈选申诉与发布版本；申诉是成绩争议流程，不能替代学习订正。
- **真正增量：** 教师从确认的薄弱点选择或起草练习，审核后发给指定学生/班级；学生记录待订正、已提交、教师反馈和再测；可回到原失分点比较，不把练习结果自动改成正式考试成绩。
- **实现边界 / 依赖：** 练习与答案需来源及授权，AI 生成题先审核正确性、难度和答案；正式考试、作业达成度、再测数据保持不同口径。跨考趋势需课程和量表可比，不能用一次补练证明掌握或疗效。
- **有意义验收：** 一条错因能追到原题、教师确认、练习版本、提交和反馈；撤回/更换练习保留历史且不误发给其他班；学生只见自己的材料；再测达成不会更改已发布考试分数，申诉状态不被订正覆盖。
- **优先级 / 规模：** P2 / L；先从现有题库人工选题启动，再验证自动推荐价值。

## A18 — 先校务字段映射，再按需接 LMS 与结果分发

- **触发场景：** 学校已有名册/成绩系统，需要导入班级身份、回写最终成绩，或把反馈材料发到指定渠道。
- **竞品证据：** [#18 CoGrader](https://links.cograder.com/ai-grading/) 的 Classroom 导入→教师审核→回写；[#14 Knowable](https://www.knowableeducation.com/pricing) 的学校 API/集成；[#25 GradeSense](https://gradesense.in/) 的 Approve & Send；[#5 百問繚乱](https://note.com/umeducation_jp/n/n274bdb4ec849) 的 Excel 转成绩系统；主 agent 复查 [#21 迈阿密大学支持页](https://lpt.it.miami.edu/platforms/supported/gradescope/index.html) 各 tab 读到 Canvas 课程/作业/名册/成绩册同步。见 [11–21](products-11-21.md)、[22–31](products-22-31.md)、[5/6/8](products-05-06-08.md)。#21 是机构支持文档，不等于本轮真实同步验收。
- **本地已有 / 对应编号：** L02、L23、L24、L26 已有名册 CSV 映射、导出与学生发布；限定检索未见明确 Classroom/Moodle/LTI 入口，不能作为全仓“没有适配器”的结论。
- **真正增量：** 先支持可保存的学校字段映射、班级/学生匹配预览与错误行；统一回写/分发任务的版本、审批、逐项回执和失败重试。国际 LMS、国内校务 API、SSO、邮件/消息渠道由实际学校需求选择一种试点。
- **实现边界 / 依赖：** 使用平台正式授权接口与最小字段，避免将外部网页自动填分列为默认方案；仅回写已发布成绩，审批时锁定接收人和版本。重复回调、远端成功本地超时先对账，不重复通知；不从研究任务发送邮件或消息。
- **有意义验收：** 用测试租户完成错字段、重复学生、撤销授权、部分回写成功和重试；回执能定位远端记录及本地发布版本；重试不会重复成绩/通知，内部备注不外传；供应商不可用时本地阅卷仍可继续。
- **优先级 / 规模：** 字段映射与回执 P2，特定 LMS/SSO/消息适配 P3；整体 L，外部接口和合同是前置依赖。

## A19 — 管理员可查的数据处理说明与模型使用账本

- **触发场景：** 学校决定是否启用某供应商、是否允许答卷图外发，关心数据去向、保存期限、删除范围和真实费用。
- **竞品证据：** [#1 Gradyn 隐私](https://www.gradyn.ai/privacy) 的控制者/处理者、子处理商、留存与删除；[#4 GroupMark](https://groupmark.com.au/privacy.html) 的本地优先/仅空白模板外发；[#14 Knowable 隐私](https://www.knowableeducation.com/about/privacy) 的未成年人、地域与携带；[#25 GradeSense 安全](https://gradesense.in/security) 的模型合作方/训练/生命周期；[#26 Grade AI](https://www.gradeai.us/security) 的私有部署声明。见本目录相应分组报告；厂商合规措辞未独立审计。
- **本地已有 / 对应编号：** L25、L27、L28；当前模型策略已有 local_only/影子/云建议/受批准升级/双供应商、图文外发开关、允许模型、预算上限、失败回人工；托管 API 已有密钥加密与连接/能力检测。增量不是新增这些治理底座。
- **真正增量：** 将现有配置、调用事实和合同事实呈现为学校可理解的清单：任务用途、实际供应商/模型版本、发出材料类型、地域声明、训练用途、留存/备份删除边界、负责人、用量/费用来源。可下载说明及按权限发起导出/删除请求，跟踪执行结果。
- **实现边界 / 依赖：** “配置声明”“供应商合同”“本次调用事实”“未获证据”分开；不得声称选择本地即整套系统完全离线，或密钥加密就证明合规。无用量不能写零费用；备份、审计与考试留存义务说明清楚，不承诺立即全链删除。不得静默换供应商绕过外发策略。
- **有意义验收：** 管理员能对一份 AI 建议查明使用了哪项策略、版本、材料类型和用量来源；仅允许文本时图片外发被阻止且仍可人工评分；模拟删除请求展示活动数据、备份和外部处理商的不同状态；无证据声明明确标未知。
- **优先级 / 规模：** P2 / L；先整理真实配置与合同依据，再决定需要补哪些执行接口。

## A20 — 教师、管理员和学生各自的上手路径与移动主任务

- **触发场景：** 新教师不知道从哪接任务；管理员准备设备与模板耗时；学生主要用手机查看结果，桌面功能过多使入口难找。
- **竞品证据：** [#14 Knowable](https://www.knowableeducation.com/) 的三类材料清单/缺项禁用；[#17 MyLesson](https://www.mylesson.ai/ai-grading) 的拍照到复核三步；[#9 慧阅卷](https://cms.17yuejuan.cn/) 的多端；[#6 巴克云](https://news.bakclass.com/news/newsArticle?newsId=555) 与 [#8 Eklavvya/Capterra](https://www.capterra.in/software/1019111/eklavvya-) 的设备、培训、支持经验；[#12 CSDN 技术文章](https://blog.csdn.net/Dev7z/article/details/154951112) 的环境说明。见 [1–10](products-01-10.md)、[5/6/8](products-05-06-08.md)、[11–21](products-11-21.md)。
- **本地已有 / 对应编号：** L01、L02、L04、L14、L24、L25、L27 已有学校登录、公共电脑选项、启用文档、角色布局、快捷键、学生端和桌面端；不能因独立教师门户是预留目录就重建教师业务。
- **真正增量：** 提供不含真实学生数据的样例考试，教师走“接任务→看冻结材料→评分→提交→回看”路径；管理员有材料/扫描设备/首考验收检查点和支持时段；学生移动端优先结果、失分反馈、申诉或补练。移动教师端先验证轻量复核场景，不直接缩小整套后台。
- **实现边界 / 依赖：** 演示数据与正式学校隔离，不自动开通外部 AI、不误发成绩；帮助可搜索并在当前任务就地解释。公共电脑偏好沿用现有边界；小屏不能遮住提交状态、原图授权、量表或人工确认，不以浏览过引导代表学会。
- **有意义验收：** 新用户各完成一个真实岗位任务，记录卡点、错误及从准备到反馈的实际耗时；手机竖屏可读题图/反馈并完成已授权操作，键盘/触控和错误状态均可使用；样例不会产生正式成绩、真实通知或外部学生数据调用。
- **优先级 / 规模：** P2 / M；先做任务观察与现有页面验证，确有缺口再改布局。

## 本轮不直接吸收的做法

| 外部做法或线索 | 判断与本地替代方式 |
| --- | --- |
| 无人值守自动提交、反思模型充当最终阅卷组长 | 只借鉴暂停、回执、重试和熔断；保留人工决定、AI_FAST_CONFIRM 狭窄范围与发布门禁。AI 独立多评不等于两名教师双评，双模型一致也不自动证明正确 |
| 修改一次规则立即影响所有答卷 | 只生成 A03 版本草稿；冻结考试重评必须另走授权和再发布 |
| 将剩余未评分全部判错、灰度判空后直接给最低分、自动点低分确认 | 不采用。未评分、缺页、识别失败、空白与答错是不同事实，A09/A10 分开处理；图像检测只形成待核对线索 |
| 改派先清空评分、共享账号轮班 | 不采用。保留提交事实、任务版本与个人责任，改派受状态限制 |
| AI/相似度检测直接认定作弊 | 不采用。候选只作人工调查线索，不自动扣分、处罚或向学生展示未经确认指控；#23 Moodle Responses 让教师并列查看并对照近似答案，本轮证据不支持将其写成系统自动查重/作弊检测 |
| 无限离线、永久保存、一次纠正永不再错、营销准确率或节时比例 | 不转为产品承诺。需要设备/样本/协议/合同证据，并说明适用范围 |
| 竞品 coming soon 和未成功访问页面中的功能 | 不立项为已验证优势。#13 GradeWiz、#29 小卷喵等缺少有效证据的细节保留待核对；#21 已由主 agent 复查获得机构支持页与官方上手页证据，固定模板 AI answer grouping 不能写成自动判分；其余复查结果以分组报告最终记录为准 |
| 直接复制开源代码、提示词或第三方题图 | 本轮未复制。将来采用前核对具体版本、许可证、依赖、模型/数据许可及现有专有代码兼容性 |
