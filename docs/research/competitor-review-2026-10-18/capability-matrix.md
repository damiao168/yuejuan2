# 全生命周期能力对照矩阵与可借鉴点目录

整理日期：2026-10-18。依据本目录六篇研究文档：README、本地基线、1–10、5/6/8 补充、11–21、22–31，以及主研究者本轮浏览器复查21/27–31的反馈。21已补读机构展开内容及官方get_started全文。这里把已取得的证据按工作链重新组织，方便逐项查找与立项；本子任务没有另行浏览器实测、登录竞品、运行竞品源码或修改业务代码。

## 如何阅读

- **已有改善**：本地 Lxx 已有基础，建议改善呈现、配置、流程或输出；不表示本轮已完成改善。
- **新增候选**：在本地基线未确认完整对应能力，适合先核对需求与实现；不等于判定本地缺失。
- **需评测**：涉及 OCR、模型效果、可靠性、权限、兼容或证据冲突，必须先取得样本与验证。
- **非当前优先**：有参考价值，但暂不建议扩展当前核心范围，或不应直接采用。

每行的 `Kxxx` 是借鉴点目录编号；来源 `#数字` 沿用用户清单的原编号，链接到保存该证据的分组报告。`Lxx` 链接到 [本地基线](local-baseline.md)。竞品的公开页面、支持文档、营销截图、厂商声明、第三方历史案例和真实登录操作不是同等证据，具体边界以各分组报告为准。下列本地判断只复用基线的有限阅读；部分源码与所有未阅读文件仍为 **pending**。

15/16 是同一 GradeLab URL，只计一份产品证据。13 GradeWiz、29 小卷喵没有可靠功能正文，不能据名称补写能力；21已由主研究者补读机构支持页和官方上手页，但没有进入真实账号评分。Coming Soon、beta、历史公告与旧版本案例均在对应行限定。没有对任何竞品判分准确率、容量、安全认证或无障碍达标作独立认证。

## 证据冲突与保守处理

整理时发现下列口径差异，已通知主研究者。本文件未擅自修改分组报告；后续补证据后应同步修正来源及总览。

1. **访问状态曾更新不同步。** 初稿曾将26–31整体描述为受限；后续已补读21机构展开内容与官方get_started、26 demo、27 AI阅卷原页、28首页、30 GitHub首页/根README、31产品矩阵/AI工具全文，29复试仍连接关闭。矩阵采用分组报告当前的细分状态：未补读子页仍仅为抓取声明；真实工作台、安装后行为与模型质量仍未验收，29无可信正文。
2. **GradeLab/Crowdmark 来源已纠正。** 11–21报告初稿16号曾出现 booklet、题目/分数/评卷人/标签过滤和评语库 Used X times，与20号Crowdmark公告重合；主研究者复读后已在分组报告纠正。本矩阵将这些具体细节只归给20号，15/16只采用队列、并排证据、摘要与校准四步，不重复计权。
3. **GradeSense 当前与套餐口径不同。** features 将多评阅流程/一致性/共识解析标 Coming Soon，pricing 的 Enterprise 又列双盲/仲裁。没有版本与交付证据时，不能将套餐文案当当前已上线事实；K070不据此增加能力权重。
4. **Knowable 现状与未来能力混列。** 定价含详细分析/报告，而主页 Detailed Reports 卡标 Coming Soon，另有年际/跨校和未来生成能力。矩阵保留公开承诺性质，不认定详细报告已实际可用。
5. **GradeOps OCR 描述不一致。** 主 README 描述 Gemini OCR，backend README 另写 Nemotron/OpenRouter OCR、Gemini 推理。没有运行配置与源码验证，本轮只借鉴分阶段思路，不指定其生产模型栈。
6. **小作坊两款产品需分开。** 主研究者浏览器分别展开后确认，AI阅卷工具写10套主题/10套评分预设，AI评测系统写20套主题；旧报告将两款产品混在同一段才产生表面矛盾。数量不作为产品优势或验收条件，实际主题质量仍未测。
