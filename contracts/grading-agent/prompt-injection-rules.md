# 提示词注入风险规则

`prompt-injection-rules.json` 是评分智能体、lab 与网关唯一的规则来源。普通作答只作为不可信证据；命中规则提供人工复核风险提示，未命中不代表文本可信，也不会绕过现有人工复核要求。

修改规则后运行 `node scripts/sync-prompt-injection-rules.mjs`，生成 Python、JavaScript、Go 的静态规则文件。CI 用 `--check` 拒绝漂移。Python 生成文件与评分智能体源码一起进入镜像，运行时不依赖宿主机仓库路径。所有运行时统一执行 NFKC、小写、去零宽字符及空白后再匹配；顺序词组使用逐段搜索，避免长文本的连续通配符回溯。

`prompt-injection-cases.json` 为三端共用的合成正反例，包含连续修饰词、角色冠词、字宽和零宽变体，以及“满分作文”等普通表达。添加规则时同时添加多个独立正例和易误判反例；不得放入真实学生数据。

“覆盖”“forget”“assign points”等也用于普通学科作答，不能单独作为评分操纵证据。“覆盖”需指向评分对象；泛指的“要求／规则／标准”需有“之前／所有／你的”等指令范围；数值 points/marks 需指向本人或当前作答。索要满分仍作为风险提示。规则只是语法线索，不能代替语义判断，也不能据此直接扣分。
